# Конфигурация Claude Code для проекта

## permissions.json

Авторазрешения для безопасных команд (чтение, git status, просмотр логов, запуск тестов).

Деструктивные операции (git push, rm, изменение файлов) всё равно требуют подтверждения пользователя.

## Использование

Claude Code автоматически применяет эти правила при выполнении команд в Bash.
