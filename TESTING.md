# Тестовая сборка Stalker Zone — как собрать и запустить

Полный список проверок по всем версиям: `CHECKLIST.md`.

**Важно.** Готовый `.jar` в этой среде собрать нельзя: доступ к репозиториям Forge/Maven/Gradle закрыт. Проект подготовлен к сборке (есть Gradle wrapper 8.8 и workflow GitHub Actions), но Forge-слой ни разу не компилировался: при первой сборке возможны мелкие правки. Чистая Java (симуляция и геометрия границ) проверена тестами.

## Вариант А. Сборка в облаке (свой ПК не нужен)

1. Создайте **приватный** репозиторий на github.com и загрузите в него содержимое папки проекта (включая `.github/`).
2. Вкладка **Actions** → workflow `build` → **Run workflow**.
3. Через 3–6 минут откройте завершённый запуск, внизу в **Artifacts** скачайте `stalkerzone-mod` (внутри `stalkerzone-0.1.0.jar`).
4. Если запуск красный, пришлите мне лог ошибки (раскройте шаг `Build mod`), я поправлю код.

## Вариант Б. Сборка на ПК

Нужен JDK 17. В папке проекта:
```
./gradlew build          (Windows: gradlew.bat build)
```
Файл появится в `build/libs/stalkerzone-0.1.0.jar`. Первая сборка скачивает Forge и Minecraft, это долго.

## Установка

1. Minecraft **1.20.1**, установщик **Forge 1.20.1-47.3.0** (files.minecraftforge.net).
2. Положите `stalkerzone-0.1.0.jar` в папку `mods` и запустите игру профилем Forge.
3. **Создание мира:** Одиночная игра → Создать новый мир → вкладка **Мир** → Тип мира → **Зона** (новый рельеф и биомы локаций), **Зона (старый рельеф)** или **Зона (плоская)**. Для версии 1.7 нужен новый мир типа «Зона». Читы включите, они нужны для команд.
4. На сервере в `server.properties`: `level-type=stalkerzone:zone` (или `stalkerzone:zone_flat`) до первого запуска.

## Что должно произойти

- Вы появляетесь у **Кордона** (0, 0) на сухом месте. Респавн после смерти пока у этой точки.
- Мир ограничен прямоугольником 2901 × 3701 блоков: забор (каменное основание, решётка 4 блока, столбы каждые 8) и за ним невидимая стена из барьеров на всю высоту. Север — это −Z.

## Чек-лист

| Проверка | Команда / действие | Ожидаемо |
|---|---|---|
| Где я | `/zone where` | ближайшая локация, владелец, расстояние до забора |
| Границы | `/zone border` | размеры прямоугольника |
| Телепорт к краям | `/zone tp ЧАЭС`, затем иди на север | у забора останавливает стена, дальше не пройти |
| Забор | дойти до края | решётки соединены, нет разрывов, тоже с воздуха |
| Невидимая стена | взять в руку барьер (`/give @s barrier`) у края | видны барьеры за забором |
| Полёт | в креативе взлететь выше забора и лететь наружу | стена не пускает |
| Возврат | `/tp @s 5000 100 5000` | через секунду вернёт внутрь |
| NPC | у Кордона (старт) подождать пару секунд | появляются сталкеры в форме Одиночек и торговец Сидорович |
| Торговец | ПКМ по Сидоровичу | в чате цены и остатки рынка |
| Предметы | творческое меню, вкладка «Зона» (или `/give @s stalkerzone:good_ammo 64`) | рубли и товары с иконками |
| Продажа | взять в руку патроны, ПКМ по Сидоровичу | стак исчез, пришли рубли, в чате сумма |
| Кошелёк | `/zone wallet` | сумма равна полученной |
| Покупка | `/zone buy еда 5 (или /zone buy food 5)` рядом с торговцем | еда в инвентаре, рубли списаны, сдача вернулась |
| Цена | `/zone market Кордон` до и после продажи большого стака | цена на этот товар упала, остаток вырос |
| Добыча | убить сталкера (не торговца) | с него падают товары и рубли; `/zone audit` сходится |
| Лагеря | `/zone tp Кордон`, подождать 5-10 секунд | вокруг вырастает лагерь: дома, вышки, костёр, торговая лавка, кольцо столбов |
| Размеры | сравнить Кордон (главная база), Дикую территорию (посёлок), блокпост «Лесной» (аванпост) | базы заметно различаются размером и набором зданий |
| Мастерская | зайти в ангар главной базы | наковальня, домна, стол кузнеца, точило |
| Кровать | казарма или медпункт, ночью лечь в кровать | сон работает |
| Усталость | `/zone status`, побегать, снова `/zone status` | значения меняются; в креативе система выключена |
| Разрушение | `/zone step 200` (штурмы и налёты), затем `/zone buildings` и осмотр пострадавших точек | у потрескавшихся и пробитых построек видны трещины, дыры, щебень и огонь |
| Вышка | подняться по лестнице на вышку | вход на площадку без прыжков через перила |
| Другие лагеря | `/zone tp Бар`, `Янтарь`, `Агропром`, `Блокпост «Лесной»` | у каждой точки свой вид и цвет фракции; на Радаре и Пси-поле построек нет |
| Перестройка | `/zone rebuild Кордон` | лагерь пересоздаётся на месте |
| Потери | убить сталкера, затем `/zone factions` | численность его фракции на 1 меньше |
| Другие точки | `/zone tp Бар`, `/zone tp Янтарь` | жители других фракций, торговцы Бармен и Сахаров |
| Аномалии | `/zone anomalies near`, пойти по координатам | в 120 блоках есть аномалии; видны частицы разного рисунка |
| Эффекты | подойти к краю поля Трамплина, Жарки, Электры (в выживании, осторожно) | подбрасывает, поджигает, бьёт током |
| Артефакт | подождать у аномалии (`/zone step 30` ускоряет симуляцию) | внутри поля появляется светящийся артефакт; в творческом меню 8 артефактов |
| Выброс | `/zone emission` | заголовок «ВЫБРОС», гроза, урон под открытым небом; под крышей безопасно |
| Смена позиций | `/zone anomalies near` до и после выброса | список аномалий изменился |
| Сила аномалий | `/zone tp Кордон`, `/zone anomalies near`, затем то же на Радаре | у Радара аномалии бьют заметно сильнее, анимация гуще |
| Ячейки | войти в выживание, открыть инвентарь (E) | открыт хотбар и один ряд, остальное заглушки; над окном строка веса и ячеек |
| Заглушки | попытаться взять заглушку или положить в закрытую ячейку предмет | заглушка возвращается, предмет перекладывается или выпадает |
| Вес | `/give @s stalkerzone:good_parts 64` ×2 | индикатор оранжевый, скорость упала; при сильном перегрузе нельзя бежать и прыгать |
| Рюкзак | `/zone buy backpack_small` у торговца (или из творческого меню) | открывается ещё ряд, предел +10 кг |
| Костюм | надеть «Зарю» и экзоскелет из творческого меню | на модели игрока виден костюм; в подсказке состояние, защита, бонус веса |
| Износ | походить в костюме у Жарки или Электры | состояние в подсказке падает, урон через изношенный костюм выше |
| Ремонт | с костюмом в руке `/zone repair` у торговца | состояние 100%, рубли списаны |
| Логова | `/zone lairs near`, затем `/tp` к координатам | у логова бродят мутанты его вида |
| Мутанты | подойти к логову | мутанты нападают; кровосос проявляется вплотную; контролёр бьёт издалека |
| Трофеи | убить мутанта | выпадает трофей; продать ПКМ по торговцу |
| Зачистка | перебить мутантов логова (`/zone lairs` сила падает) | сообщение «Логово уничтожено», выпадают артефакты; `/zone audit` сходится |
| Яйца | творческое меню, яйца призыва мутантов | все 7 видов появляются с моделью и текстурой |
| Симуляция | `/zone factions`, `/zone step 100`, `/zone audit` | аудит сходится |
| Монолит | `/zone wake`, `/zone events 20` | события войны |

Известные ограничения: NPC не видят друг друга за пределами 110 блоков от игрока (там живёт только симуляция); рельеф пока обычный ванильный (без структур Зоны); КПК в игре ещё нет. Аномалии рисуются только рядом с игроком (72 блока), мутанты живут у логов в 110 блоках от игрока. Текстуры мутантов пока простые, заглушки до отдельных моделей.
