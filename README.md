# Stalker Zone — живая Зона в Minecraft

Мод для Minecraft 1.20.1 (Forge 47.x). Затяжная война группировок, живая экономика
с законом сохранения, сталкеры как личности. Основа мира — авторская карта **TheZone**:
локации уже построены, проект размечает их и привязывает логику, а не строит заново.

## С чего начать

| Документ | О чём |

## Проверки реестра

    python tools/registry/validate.py
    python tools/registry/check_links.py

Оба запускаются в CI на каждом PR, трогающем реестр.

## Сборка

    gradlew.bat build

Готовая сборка — релиз `nightly`, обновляется при слиянии в main. Модпак собирается
скриптом `stalker_tools/modpack.ps1`, TaCZ ставится `get_tacz.ps1`. Версии зависимостей
зафиксированы в `docs/01-IDS.md` §7; менять их — отдельной задачей с проверкой боя.
