# FramedBlocks в постройках: замер на штабе Волка и где применять (П-05, 06.11.2026)

Пробник — штаб Волка (изба 2 деревни, (18, −8), PR #73): кровля — `framed_slope` с камуфляжем `zm_shifer`, наличники — `framed_wall_board` (крашеное дерево), подоконники — `framed_slab_edge`. Без мода — запасной вид: ступени шифера, без наличников и подоконников.

## Замер

**Block entity** (счёт по сборщику `KordonVillage`, уровень 1; каждый framed-блок — block entity с NBT камуфляжа):

| | без FramedBlocks | с FramedBlocks |
|---|---|---|
| штаб Волка (x 9..27, z −15..−1) | 4 (койки) | **256**: 204 ската кровли, 36 наличников, 12 подоконников, 4 койки |
| вся деревня (сейчас framed только штаб) | 79 (койки, бочки, печи, варочная стойка) | 331 |
| вся деревня, если framed все кровли и окна (оценка) | 79 | ≈ 1 700 (1 296 ступеней кровли + ≈ 86 окон × 4 доски) |

**Сервер** (облако, `.szl` пользователя, новый мир, view 8; деревня загружена принудительно, 30 с простоя):

| | без FramedBlocks (`-PnoFramed`) | с FramedBlocks 9.4.3 |
|---|---|---|
| создание мира | 37,6 с | 38,8 с (в пределах разброса) |
| средний тик мира | 0,54 мс | 0,54 мс |
| размер файлов региона после сохранения | 2,90 МБ | 2,89 МБ |
| скат кровли штаба (18, 83, −14) | `zm_shifer_stairs` | `framedblocks:framed_tile` + `camo: zm_shifer` (NBT на месте) |

Framed-блоки не тикают: на сервере их стоимость — только NBT в чанке (~100 байт на блок) и загрузка чанка; на тике и создании мира разницы не видно.

**FPS — только на ПК игрока** (в облаке нет видеокарты и клиента). Как мерить: `docs/checklist/p05-framed-probe.md`, П05.2 — F3, 30 с у штаба и 30 с у соседней избы, с jar FramedBlocks и без. Ожидание: framed-блоки рисуются в сетке чанка (запечённая модель с камуфляжем), а не каждый кадр, как сущности, — на FPS влияет только перестройка сетки чанка при изменении блоков (ломать, ставить). Если на ПК у штаба FPS просядет больше чем на ~10 % — вывод ниже пересмотреть.

## Вывод: где применять

1. **Кровли всех изб и построек баз — да.** Это главный выигрыш вида (ровный скат 45° вместо «лесенки»), а цена — ≈ 200 неактивных block entity на избу. Деревня целиком — ≈ 1 700, это нормально для Minecraft (сундучная комната игрока — сотни таких же).
2. **Окна и двери на видных постройках — да** (наличники, подоконники): штаб, медпункт, бункер (портал), позже застава О7. На казармах и складах — по желанию.
3. **Нет:** стены, полы, заборы, тропы, рельеф, массовый мусор и обломки — там ванильные и наши полные блоки, плиты и ступени. Framed-блок без нужды — лишний block entity.
4. **Граница — около 2 000 framed-блоков на базу (площадку).** Больше — сначала замер FPS на ПК.
5. Без FramedBlocks всё работает (запасной вид), поэтому мод остаётся необязательным; в модпак — включать.

Следующий шаг (если пользователь одобрит после П05.2): кровли остальных шести изб деревни на framed-скатах — одна строка в `KordonVillage.framed(House)`.
