# Постройки Кордона по оригиналу — как собирать

Обмеры снятые с геометрии уровня S.T.A.L.K.E.R. Anomaly (`l01_escape.szl`): следы, высоты, материалы — **только цифры**,
сами данные игры в репозиторий не кладутся. Файлы `NN-*.md` — по узлам сценария.

## Метод (как у южного блокпоста)
1. По таблице и картам высот понять объект: где стены (высота держится по краю), какой формы крыша (профиль высот поперёк:
   растёт к середине — двускатная вдоль длинной оси; растёт со всех сторон — вальмовая; ровная — плоская), этажность
   (высота 7–10 — два этажа), проёмы (провалы в стене по краю), заборы (линии высотой 2–4), вышки (малый след, высота 9+),
   техника (материалы «техника», «военная техника» — ставить `Vehicles` ближайшего вида), мешки.
2. Сборщик — класс в `zonemap/build/` по образцу `KordonSouthPost`: те же помощники (`box`, `gableZ`, `hip`, `flat`, `floor`,
   `door`, `window`, `tower`, `line`), **те же координаты и размеры, что в обмерах** (допуск ±1 блок), материалы — по таблице
   кодов → блоки `stalkerzone:zm_*` (кирпич → `zm_brick_red`, бетон → `zm_concrete`, доски → `zm_planks_gray`, шифер → `zm_shifer`,
   ржавый металл → `zm_rust_sheet`, профлист → `zm_corrugated`, мешки → `zm_sandbags`).
3. Границы замены `CLEAR` — прямоугольник(и) вокруг объектов с запасом 2–4 блока; внутри воксели уровня не ставятся.
4. Регистрация в `Prefabs` (список сборщиков уровня), рабочие места (`mark`, карточка 031) — посты, нары, костёр, мастерская,
   маршрут патруля.
5. Тест в `PrefabsTest`: блоков > N, все в границах, нет пересечения границ разных сборщиков.
6. Уровень развития 0–3: на 0 выбиты блоки и нет стёкол, на 3 — мешки, решётки, колючка (как в образце).

Внешний вид проверяет игрок в игре (новый мир) и пишет `/баг`; превью: `bash tools/prefab/preview.sh <szl> <png>` (у кого есть файл уровня).
