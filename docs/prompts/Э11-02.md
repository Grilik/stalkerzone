## Шаги
1. Инструмент `tools/sound/build_sound_pack.py`: читает папку распакованных звуков игры (путь — аргумент), по таблице `tools/sound/sound_map.json` («событие мода → файл оригинала») собирает ресурспак звуков в папку игрока; конвертация в ogg моно/стерео по назначению. В git — только инструмент и таблица.
2. События мода — `sounds.json` в jar с пустыми запасными звуками: без пака мод работает тихо, без ошибок.
3. Категории: окружение по локациям и времени суток (ветер, птицы, дальние выстрелы и вой — редкие случайные), Гейгер (частота от дозы), детекторы, 14 видов аномалий (гул, срабатывание), мутанты по видам (голос, атака, смерть), шаги по поверхностям, интерфейс КПК и инвентаря, выброс.
4. Оружие — звуки пака TaCZ; замену на оригинальные делать только если пак это позволяет без правки чужого jar.
5. Громкость и дальность — по категориям Minecraft; позиционные звуки — не больше N одновременно (лимит источников).
6. Отчёт инструмента: какие события остались без файла.

## Разрешённые файлы
`tools/sound/*`, `assets/stalkerzone/sounds.json`, регистрация событий звука в коде (`ModSounds`), места вызова (аномалии, детектор, `survival/Radiation`, мутанты, выброс), `client/ZonePacks.java`.

## Проверка и приёмка
Сборка пака на ПК пользователя проходит, отчёт без пропусков по обязательным категориям; без пака — запуск без ошибок в логе; в git нет звуковых файлов игры.
