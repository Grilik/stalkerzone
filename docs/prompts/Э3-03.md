# Э3-03: метки на карте — базы, логова, аномалии, отряды с маршрутом, контракты, рюкзак, укрытия

Автор: Fable, 16.11

**Исполнитель:** ведущий (Opus); чистая часть снимка — карточка конвейера → `@sim-worker`
**Цель:** на карте Xaero в КПК видны метки мода по знаниям игрока: статичные — путевыми точками набора «Зона» (и на миникарте), динамика — своими значками поверх карты (решение в2, в-П1).

## Шаги
1. **Первым — разведка преобразования «блок → экран»** текущего вида `GuiMap` (поля центра и масштаба или пересчёт). Не получается надёжно — динамика рисуется только на запасной карте мода, статика остаётся путевыми точками; сообщить штабу до остальной работы.
2. Карточка конвейера `PdaMarksTest`: снимок для игрока содержит только объекты и отряды из `PlayerIntel`; у отряда — позиция последнего сведения и давность в днях; не больше 200 меток на игрока (ближайшие); локации без симуляции — строка «нет данных».
3. Статика (набор путевых точек «Зона», полностью принадлежит моду, переписывается при изменении знаний): базы (с `tier`), крупные аванпосты и блокпосты, торговцы, укрытия. Малые аванпосты и сектора на общей карте не показывать. Имя — из атласа, цвет — фракции владельца, владелец — группа. Отключается настройкой в КПК.
4. Динамика (`ScreenEvent.Render.Post`, только на `GuiMap` из КПК): отряды со стрелкой и линией маршрута, давность — блёклостью; логова и аномальные поля, которые игрок знает; цель и район контракта; рюкзак смерти; при предупреждении о выбросе — подсветка ближайшего известного укрытия с местом.
5. Обновление с сервера раз в 2–5 с, между обновлениями — интерполяция; подсказка при наведении; клик по базе — карточка справа (данные П-09, если есть).
6. Те же метки рисует запасная карта мода — один источник `PdaModel`.

## Проверка и приёмка
`PdaMarksTest` и круговой тест Э0-12 зелёные; в игре метка базы совпадает с местом в мире (ошибка ≤ 2 блоков на любом масштабе); 200 меток — FPS на карте не падает больше чем на 10 %; сервер не шлёт незнакомое (дамп снимка нового игрока: только стартовые знания).

## Видно в игре
КПК → «Карта»: значки деревни и торговца после посещения, отряд с линией маршрута после встречи, цель взятого контракта, свой рюкзак после смерти; на миникарте — точки открытых баз.

## Чек-лист для игры
- Новый игрок: на карте только стартовое место. Дойти до АТП — появилась метка.
- Встретить отряд, отойти — метка остаётся на месте встречи и блёкнет.
- Взять контракт — цель на карте. Умереть — метка рюкзака.
