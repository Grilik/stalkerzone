# Э1-11: новый мир = копия TheZone — золотая копия vN, кнопка «Зона», свой сид симуляции

**Исполнитель:** ведущий (Opus) — Minecraft-код (клиент) + скрипт
**Цель:** игрок создаёт мир кнопкой «Зона» в меню: копия золотой копии, свой `simSeed`, режим игры и снимок карты Xaero; золотая копия очищена перед раздачей (решение а3, в3, ревью §4).

## Прочитать
- `docs/claude/decisions/` (а — мир, б — атлас, г — симуляция, `review-fable.md`), `docs/thezone/01-bedrock-original.md`, `02-materials.md`, `places.json`, `img/overview.png`; `decisions/v-pda-xaero.md` в3.

## Шаги
1. Золотая копия vN: рабочая копия после Э1-10/Э1-12/прогрева/постановок → чистка (`playerdata/`, `stats/`, `advancements/`, `data/stalkerzone_sim.dat`, ванильные `data/*.dat`, `session.lock`, старые `StalkerEntity`; время и погода в `level.dat`) → проверка → архив + md5.
2. Код копирования (общий для кнопки, сервера и CI): копия, манифест (`simSeed`, `goldenVersion`, `atlasVersion`), `level.dat` (`GameType`, `allowCommands`, точка появления, генератор за краем — ванильный `flat`).
3. Кнопка «Зона» в экране создания мира: копирование **до** запуска встроенного сервера, отдельный поток, экран прогресса, проверка места на диске, затем `WorldOpenFlows.loadLevel`; для творческого — снимок карты Xaero после выбора окончательного имени папки.
4. Правило стабильности ID блоков и предметов мода — в `docs/claude/00-start-here.md`.

## Разрешённые файлы
`src/main/java/ru/stalkerzone/client/*` (экран), `src/main/java/ru/stalkerzone/world/*` (манифест), `tools/thezone/*`.

## Проверка и приёмка
Два мира кнопкой: разные `simSeed`, через 3 игровых дня разное состояние; творческий — карта видна целиком; выживание — нет; в золотой копии нет данных оператора.

## Чек-лист для игры
- Пользователь: «Зона» → творческий → карта Xaero целиком; «Зона» → выживание → появление в точке атласа.
