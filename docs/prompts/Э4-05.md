# Э4-05: кодек сохранения со стабильными id

Автор: Fable, 16.11

**Исполнитель:** ведущий (Opus); чистая часть — карточка К14 → `@sim-worker`
**Цель:** сохранение симуляции — секции со своими версиями и миграциями; обновление мода больше не сбрасывает историю мира, пока не меняется набор узлов атласа (г6).

## Прочитать
- `g-simulation-whole-zone.md` г6, карточки К6, К14; `review-fable-2.md` раздел 4 «Сохранения» (секция-хвост v24 — первый шаг этого кодека), г-П11; `sim/Simulation.java` (`save/load`, `SAVE_VERSION`), `ZoneData.java`; промпты Э0-10 (enum), Э0-14a/b (сброс и `.bak`), Э1-11 (манифест, `simSeed`).

## Шаги
1. `sim/SaveCodec`: заголовок (магия, версия формата, `simSeed`, сценарий, версия атласа) + секции `[имя, версия, длина, байты]`. Тело v23/v24 разрезается на секции по подсистемам: узлы, группы и фракции, люди, отряды и караваны, логова, аномалии, контракты, `Ledger`, сектора, укрытия, `worldLoot` и остатки бюджетов контейнеров, знания игроков (Э3-08), очередь шлюза. Блоки секции-хвоста становятся секциями без изменения содержимого.
2. Ссылки: узлы, сектора, группы — строковый id атласа (таблица «id → индекс» строится при чтении); enum — по имени; отряды и люди — их id. В рантайме индексы остаются `int`.
3. Чтение старого: конвертер v23 и v24 (тело + хвост) → секции. **Эталонные сохранения** в `src/test/resources/saves/`: v23 и v24 `kordon`, далее по одному на каждую версию, выданную пользователю.
4. Миграции — цепочка чистых функций на секцию. Незнакомая секция пропускается, но **сохраняется при перезаписи** (откат версии мода не теряет данные); отсутствующая — заполняется из сценария и атласа.
5. Изменения атласа: узел удалён — люди и склад уходят на ближайшую базу своей группы; сектор удалён — в склад группы; переименование — таблица синонимов в атласе.
6. После загрузки — `audit()`; не сходится → откат на `.bak` и сообщение игроку (механизм Э0-14b).
7. Сброс пересоздаёт только симуляцию; журнал постановок `placements.jsonl` не трогает и **уровни из него не читает** (уровни баз отложены) — оставить точку расширения и комментарий. `simSeed` — из манифеста мира.
8. Запись атомарная (временный файл → переименование), замер времени.

## Разрешённые файлы
Новый `sim/SaveCodec.java`, `sim/Simulation.java` (save/load), подсистемы `sim/*` (свои секции), `ZoneData.java`, `src/test/resources/saves/*`, тесты, `docs/tasks/*`, `tools/ci/test_sources.sh`.

## Проверка и приёмка
К14 (`SaveSectionsTest`): незнакомая секция пропущена и сохранена, enum по имени, эталоны v23 и v24 загружаются, круг «загрузить → сохранить → загрузить» даёт равное состояние, `audit()` сходится. Сохранение Кордона ≤ 300 КБ, синтетической Зоны ≤ 2 МБ, запись ≤ 50 мс. Сохранение пользователя из `TheZone-trial` открывается новой версией без сброса.

## Видно в игре
Обновить мод в существующем мире — группы, склады, знания и контракты на месте, сообщения о сбросе нет.
