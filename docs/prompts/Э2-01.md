## Шаги
1. Режим запуска `-Dstalkerzone.place=<id,…>`: копия затронутых регионов → билеты `forceload` (площадка + 1) → ждать FULL → высота (для `adapt` — пол здания; для `redesign`/пустых — медиана «земли» по живым чанкам, сверка с растром ±2) → сборщик частями (≤ 5 мс/тик, ≤ 2 000 блоков, первый проход `2|16`, второй — формы; `ObjPropBlock.PLACING` снят) → журнал → `save-all flush` → выход.
2. `CLEAR` по умолчанию выключен; висящие сущности (картины, рамки, стойки) — опорные блоки не трогать.
3. `--undo <id>` (регионы не менялись позже), повтор без `--force` — отказ.
4. `/zone place` — обёртка для оператора под `-Dstalkerzone.ci=true`.
