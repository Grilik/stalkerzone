# Э1-05: разметка оригинала — смарт-террейны уровней Anomaly/CoC с типом и группировкой

**Исполнитель:** ведущий (Opus); извлечение — локальные скрипты `tools/xray`
**Цель:** по каждому уровню оригинала есть разметка: базы, заставы, ресурсные точки, логова, аномальные поля, переходы — с типом и стартовой группировкой, в координатах Minecraft-ориентации (решение б2, ревью §5 п. 1).

## Шаги
1. `tools/atlas/import_level.py <level> <loc> --original-only`: смарт-террейны уровня (`kamp`, `sleep`, `guard`, `comander`, `walker`, торговцы, `level_changer`, аномальные зоны), тип и группировка из конфигов смарт-террейнов (CoC/Anomaly); координаты `original` = (xr_x, −xr_z).
2. Подтвердить у пользователя источник уровней: Затон и Янов — уровни ЗП из Anomaly, Мёртвый город, Лиманск, Болота — Anomaly 1.5.x.
3. Выход в атлас-черновик `atlas/locations/<loc>.json` со статусом `observed`, без данных игры (только координаты, типы, ID смарт-террейнов).
