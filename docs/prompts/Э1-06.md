# Э1-06: соотнесение TheZone с уровнями — опорные точки, преобразование, невязка

**Исполнитель:** ведущий (Opus) + пользователь (якоря по F3); при неясностях — `@architect`
**Цель:** для каждой локации — подобие «уровень → TheZone» по ≥ 5 якорям с ошибкой без одного якоря в пределах порога, либо деление на части, либо ручная расстановка (решение б2, ревью §5).

## Прочитать
- `docs/claude/decisions/` (а — мир, б — атлас, г — симуляция, `review-fable.md`), `docs/thezone/01-bedrock-original.md`, `02-materials.md`, `places.json`, `img/overview.png`;

## Шаги
1. `tools/atlas/fit.py <loc>`: подобие без отражения по якорям (наименьшие квадраты), `rms`, `max`, `loo.max`, масштаб, угол; отрицательный определитель — ошибка ввода.
2. Кордон первым: кандидаты якорей от Э1-04 → пользователь подтверждает 5–6 по F3 (≈ 15 мин) → проверка здравого смысла (узел 0 ≈ (−4122, 3478), масштаб ≈ 1).
3. Не сходится (`loo.max > 16` или `rms > 8`) — деление по картине остатков; не сходится и так — ручная расстановка, статус `observed`.
4. Записать `transform`, `anchors`, `residual` в `atlas/locations/<loc>.json`.
