## Шаги
1. Решение (варианты — в PR, выбирает пользователь): (1) мод Create как зависимость — его рельсы и поезда, тяжёлая зависимость и риск для FPS; (2) **свои блоки по образцу** — широкая колея и вагоны как модели-блоки мода, без движения (допущение: это, поезда в Зоне стоят); (3) только перерисовать ванильные рельсы паком — дёшево, но не «крупнее».
2. Вариант 2: блоки колеи (прямая, поворот, стрелка, уклон), шпалы и балласт, контактные опоры, тупик; вагоны и локомотив — многоблочные модели (товарный, цистерна, платформа, электричка).
3. Замена в мире — инструментом в рабочей копии: трасса существующих рельсов TheZone (из съёмки) → широкая колея по оси, насыпь по стандарту; журнал, откат, превью «до/после» по каждой локации. В рантайме блоки не пишутся.
4. Проходимость: колея и насыпь проходимы для NPC и караванов (рёбра «ж/д» графа маршрутов остаются); вагоны — укрытия (`cover`) и контейнеры добычи по правилам Э1-17 (без пополнения).
5. Начать с Кордона (насыпь и мост) как образца; затем депо Свалки, вокзал Бара, Янов.
6. Цена для FPS: модели вагонов — с упрощением вдали; замер по Э11-03.
