# Э3-08: знания игрока — что он открыл и откуда узнал

Автор: Fable, 16.11

**Исполнитель:** конвейер (карточка → `@sim-worker`), подключение к миру — ведущий (Opus)
**Цель:** сервер знает, какие объекты атласа и какие отряды известны игроку; снимок КПК отдаёт только это. Клиент сам ничего не открывает (решение в2, туман войны мастер-спецификации).

## Прочитать
- `v-pda-xaero.md` в2 («Видимость по знаниям»); `review-fable.md` §2 «Решение в»; `sim/PdaSnapshot.java`, `ZoneData.java`, `npc/PlayerFaction.java`; схема атласа `atlas.schema.json`.

## Шаги
1. Чистый класс `sim/PlayerIntel`, два хранилища.
   - **Постоянное:** строковый id объекта атласа → день и источник (посещение, торговец, контракт, свои, чужой КПК). Не сбрасывается при сбросе симуляции (атлас тот же). Хранится в `ZoneData` отдельным блоком по игроку, вне байтов `Simulation`.
   - **Зависящее от симуляции:** сведения об отрядах (id отряда, позиция, день) — в секции-хвосте сохранения по игроку, сбрасываются вместе с симуляцией.
2. Источники: посещение (игрок ближе R блоков к объекту; R по виду объекта, для базы — вход на территорию `area`); покупка сведений у торговца (деньги — в кассу торговца); выданный контракт открывает цель; «свои» — объекты и отряды группы игрока и её фракции, пока он в ней состоит (до Э7-06 — по владению, после — из `IntelView`; игроку не копируются); прочитанный чужой КПК (Э3-07).
3. Отряд известен, если был в поле зрения сущностью (уровень А) или сообщён своими; хранится последняя позиция и день.
4. Стартовые знания — место появления и ближайший торговец (из сценария).
5. Творческий режим: все статичные объекты и отряды видны (режим оператора) — **допущение, подтвердить у пользователя**; в `PlayerIntel` не записывается.
6. Карточка `PlayerIntelTest`: новый игрок знает только стартовое; посещение добавляет запись один раз; сброс симуляции стирает отряды и сохраняет объекты; объект, удалённый из атласа, молча выпадает; выход из группы убирает «своих», но не то, что видел сам; сохранить → загрузить — равно.
7. Проверка близости — раз в секунду на игрока, только по объектам его локации.
