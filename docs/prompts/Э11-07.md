# Э11-07: музыка и саундтрек оригинала

Автор: Fable, 16.11

**Исполнитель:** ведущий (Opus); пользователь — файлы игры
**Цель:** музыка серии: меню, эмбиент по локациям и времени суток, бой, выброс, гитара у костров, радио в лагерях; тишина — тоже часть звука.

## Прочитать
- Итог Э11-02 (сборщик пака, таблица соответствия, запасные пустые звуки); словарь действий точек (Э6-05: гитара, костёр); `client/ClientEmission.java`; стадии тревоги (Э10-06).

## Шаги
1. Расширить `tools/sound/sound_map.json` разделом музыки; сборщик кладёт треки в тот же локальный пак. В git — только таблица.
2. Музыкальный диспетчер на клиенте (один): состояние — меню, спокойно (трек локации по времени суток), напряжение (стадия «ищет»), бой, выброс, подземелье. Переходы — затуханием 2–4 с; после трека — пауза тишины 1–3 минуты (параметр).
3. Локация игрока — по атласу; у каждой локации список эмбиентов; ванильная музыка в режиме `THEZONE` отключена.
4. Источники в мире: гитара — позиционный звук от NPC с действием «гитара» (трек выбирается от `PersonId` и дня, слышен в 16–24 блоках); радио — блок или точка лагеря с позиционным звуком (переговоры, музыка); громкоговорители баз (Долг, Свобода) — редкие объявления.
5. Выброс: сирена базы, нарастающий гул, после — тишина.
6. Настройки: громкость музыки мода отдельно (категория Minecraft «музыка»), выключатель радио.
7. Без пака — тишина без ошибок.

## Разрешённые файлы
`tools/sound/*`, новый `client/MusicDirector.java`, `assets/stalkerzone/sounds.json`, `ModSounds`, `npc/CampfireGoal.java` или цель действий точки (сигнал «играет»), блок радио (если нужен — `block/`), `client/ClientEmission.java`.

## Проверка и приёмка
Переходы состояний без наложения двух треков; гитара слышна только рядом; без пака лог чистый; потеря FPS — нет.

## Видно в игре
Вечером у костра кто-то берёт гитару; на Кордоне — знакомый эмбиент, в бою он сменяется, после — долгая тишина с ветром.

## Чек-лист для игры
- Посидеть у костра до гитары.
- Войти в бой и выйти — музыка сменилась и вернулась.
- Пережить выброс со звуком.
