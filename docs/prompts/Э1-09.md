# Э1-09: режим мира TheZone — без записи при загрузке чанка и тиковых писателей, генератор за краем

**Исполнитель:** ведущий (Opus) — Minecraft-код
**Цель:** в мире с манифестом TheZone мод не пишет блоки ни при загрузке чанков, ни старыми тиковыми писателями; за краем данных — ванильный `flat`; мир без манифеста, похожий на TheZone, тоже защищён (решение а1, ревью §1 п. 1–2).

## Прочитать
- `docs/claude/decisions/` (а — мир, б — атлас, г — симуляция, `review-fable.md`), `docs/thezone/01-bedrock-original.md`, `02-materials.md`, `places.json`, `img/overview.png`; код: `world/ZoneWorld.java`, `WorldDecorator`, `XrayPlacer`, `PrefabLayer`, `ZoneMapPlacer`, `LinkRoads`, `WallBuilder`, `StructureManager` (`Camp`, `RadioactiveSpots`, `Dressing`, `Landmarks`), `LandmarkManager`, `BridgePost`, `ZoneCommands`, `StalkerZoneMod.onServerTick`.

## Шаги
1. `world/WorldMode` (`LEGACY`/`THEZONE`) по манифесту `stalkerzone/world.json` на `ServerAboutToStartEvent`; защита: seed TheZone + чанки на x −6656 без манифеста → `THEZONE` без постановок + предупреждение.
2. В `THEZONE`: `ZoneWorld.onChunkLoad` ничего не вызывает; `StructureManager.tick`, `ZoneMapPlacer.tick`, `LandmarkManager.tick`, `BridgePost.tick` не пишут; `WallBuilder` не используется; флаг `ZoneWorld.IN_CHUNK_LOAD` — любая запись мода при нём → ошибка в лог и `chunkWrites`.
3. `built`/`campY`/`rendered` в `THEZONE` не читаются; точка появления — из атласа (заготовка до Э1-13).
4. Тест-сканер (расширение `ChunkLoadPlaceTest`): точки входа загрузки чанка и тиковые писатели начинаются с проверки режима.
5. Старые `StalkerEntity` в `entities/` золотой копии удаляются шагом чистки (Э1-11).
