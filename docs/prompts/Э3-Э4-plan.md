## Общие правила (для всех промптов Э3–Э4)
- Действуют «Общие правила» из `docs/prompts/Э2-01.md` (роли, одна задача — одна ветка — один PR с номером в заголовке, мир и данные GSC не трогать, запрет записи блоков при загрузке чанка, подпись коммитов).
- **Сохранение.** До Э4-05 новые данные пишутся только в секцию-хвост (вводит Э2-17, v24): блок `[имя, версия, длина, байты]`, незнакомый пропускается, отсутствующий заполняется из сценария и атласа. Тело v23/v24 не менять; сброс истории пользователя — только при смене набора узлов. Ссылки — строковые id атласа, не индексы.
- **Деньги и вещи физичны.** Ничего не возникает и не исчезает: деньги — из кассы плательщика, вещи — со склада; таймеров уничтожения нет; `destroyed` — только расход. Игровой код не пишет поля симуляции напрямую (после Э4-04 это ловит тест-сканер).
- **Цены** — только `data/stalkerzone/prices/prices.json` через `economy/Prices` (Э8-09); `Good.base` для сделок с игроком не использовать.
- **Группы** (Э2-17): владелец базы, склада, кассы, отряда — группа; фракция выводится. Цвет на карте — фракции.
- **Еда и вода** только привозные (Э8-08): в интерфейсах нет «производит еду».
- **Xaero** — только через `compat/XaeroMap` отражением, с флагом `reflectFailed` и запасным путём; jar Xaero в репозиторий не класть (лицензия ARR).
- **Сеть.** Несовместимое изменение пакетов — поднять `VERSION` в `net/Net.java`; сервер шлёт только то, что игрок знает (Э3-08).
- **Тесты** — `main()` в `src/test/java/ru/stalkerzone/…`, каждый добавить в `tools/ci/test_sources.sh`. Карточки конвейера — `docs/tasks/`, с полем «Видно в игре» (`docs/claude/06-conveyor-v2.md`, правило Э0-16).
- **Экраны** — набросок картинкой в PR до кода (`docs/claude/04-interfaces.md`, «Порядок»).
- Локации без симуляции (всё, кроме Кордона, до Э5) на карте и в КПК — «нет данных», без меток отрядов.
