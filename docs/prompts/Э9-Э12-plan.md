## Общие правила (для всех промптов Э9–Э12)
- Действуют «Общие правила» `docs/prompts/Э5-Э8-plan.md` (сохранение секциями, физичность денег и вещей, цены из `prices.json`, группы-владельцы, привозная еда, выброс без потери точек, знания вместо всеведения, пороги производительности, тесты и карточки, наброски экранов).
- **Звук и музыка оригинала** собираются локально из файлов игры пользователя инструментом; в git — только инструмент и таблица соответствия, не файлы.
- **Клиент.** Замер FPS — на профиле «лёгкий» и «с шейдерами» (Э11-03); новая клиентская система не должна отнимать больше 5 % кадра на ноутбуке пользователя.
- **Сторонние моды** (TaCZ, Xaero, Create, шейдеры) — только через `compat/` с запасным путём; jar в git не класть.
- **Мультиплеер** (с Э12-03, но держать в уме всегда): состояние — на сервере, клиенту — только известное игроку; никаких `static` с состоянием мира на общей стороне.
