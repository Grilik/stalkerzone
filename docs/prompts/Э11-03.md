# Э11-03: ресурспак и шейдеры, замеры FPS

Автор: Fable, 16.11

**Исполнитель:** ведущий (Opus) + пользователь (замеры на ноутбуке)
**Цель:** выбрать и зафиксировать облик: пак TheZone, шейдер и оптимизаторы; два профиля — «лёгкий» без шейдеров и «красивый»; числа FPS и тика на ноутбуке пользователя (Ryzen 7 5800H, RTX 3050) — мерило для всех следующих задач.

## Прочитать
- Строка Э11-03 в `docs/roadmap.md` (кандидаты: Embeddium + Oculus, Complementary, MakeUp); `docs/thezone/02-materials.md` (пак TheZone, Э1-01), `client/ZonePacks.java`; `.claude/skills/stalkerzone-dev/SKILL.md` (доставка игроку); `ServerWatchdog.java`, `/zone perf`.

## Шаги
1. Маршрут замера (5 минут, одинаковый): деревня новичков → дорога → мост → база с 30+ NPC → бой; записываются средний и 1 % низкий FPS, медиана и максимум тика, память.
2. Матрица: без оптимизаторов / Embeddium / Embeddium + Oculus с Complementary / с MakeUp; дальность прорисовки 8, 12, 16. Замеры делает пользователь по инструкции (команда записи — `/zone bench start|stop`, пишет файл в папку игры).
3. Профили: «лёгкий» (без шейдеров, дальность 8–10, упрощённые анимации и частицы мода) и «красивый» (выбранный шейдер, настройки под Зону: туман, пасмурное небо, тёплый свет костров). Настройки шейдера — файлом, который ставит инструмент доставки.
4. Совместимость пака TheZone с шейдером: непрозрачные полные блоки (PR #154), светящиеся блоки, вода, листва Рыжего леса.
5. Опции мода для клиента: плотность частиц аномалий, дальность отрисовки NPC и меток — в настройках, по умолчанию из профиля.
6. Итог — `docs/claude/perf-baseline.md`: таблица замеров и выбранные профили; пороги для будущих задач («не хуже базовой линии больше чем на 5 %»).
7. Jar сторонних модов и шейдеры в git не класть — список с версиями и ссылками.

## Разрешённые файлы
`ZoneCommands.java` (`/zone bench`), клиентские настройки мода, `client/ZonePacks.java`, инструмент доставки навыка `stalkerzone-dev`, `docs/claude/perf-baseline.md`.

## Проверка и приёмка
Таблица замеров заполнена пользователем; на «лёгком» профиле ≥ 60 FPS средний и ≥ 30 FPS 1 % низкий на маршруте (допущение, правит пользователь), сервер 20 TPS; оба профиля ставятся одной командой.

## Видно в игре
Серое небо, туман над болотом, свет костра на лицах — и при этом игра не тормозит на ноутбуке.

## Чек-лист для игры
- Пройти маршрут замера на двух профилях, прислать файлы.
- Выбрать шейдер из двух по скриншотам одного места.
