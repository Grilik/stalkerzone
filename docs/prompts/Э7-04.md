# Э7-04: экспансия — разведка, занятие зон, потеря баз

Автор: Fable, 16.11

**Исполнитель:** `@sim-worker` по карточке К11 `ExpansionTest` (критерий — по г-П9); ведущий — сведение
**Цель:** группы расширяются осмысленно: оценивают зоны потенциала, разведывают, занимают существующие постройки TheZone и запускают там сектор; теряют точки боем, набегом и оставлением. Стройки нет.

## Прочитать
- Решение г) г4 «Экспансия и потеря баз» с поправками г-П9, г-П10, г-П13; карточка К11; итог Э1-16 (`kind: zone`, `potential{}`), Э7-06 (`IntelView`); `sim/FactionBrain.java`, `sim/UtilityBrain.java` (ценность узла — после Э8-08 без `farmCap`), `sim/Group.java`, `sim/Logistics.java` (снабжённость).

## Шаги
1. К11 переписать под г-П9: «новая точка занимается только после разведки (уверенность ≥ 0,6) и только в зоне с постройками; сектор начинает работать при людях и снабжении; при снабжённости < 40 % 10 дней — оставление с эвакуацией склада».
2. Оценка зоны группой: нужда в ресурсе (чего не хватает складу: детали, дерево, части мутантов, артефакты, торговое место, укрытие), угрозы по знаниям, длина снабжения до главной базы, свободные люди.
3. Порядок: разведотряд → запись в карту знаний → отряд занятия идёт и встаёт в постройки зоны → зона становится малой базой группы (узел уже есть в атласе, владелец меняется с «ничей») → первый караван снабжения.
4. Лимиты: не больше `люди / 8` узлов на фракцию и лимита доктрины; содержание растёт быстрее линейного; вместимость укрытий — гарнизон сверх неё несёт потери при выбросе.
5. Потеря: захват (осада — есть), набег мутантов, оставление по снабжению. Выброс точку не отнимает. Оставленная точка — ничья, её склад вывезен или остался «на поле».
6. Ресурс зоны конечен и восстанавливается с задержкой: истощённую зону группа оставляет сама.
7. Блоки не пишутся; «лагерь уровня 0» и заказ постановки из старого текста г4 не реализуются.
