# Э12-04: финальная приёмка и сборка 1.0

Автор: Fable, 16.11

**Исполнитель:** пользователь + ведущий (Opus)
**Цель:** версия 1.0 принята пользователем по чек-листу и собрана в комплект «мир + мод + паки + инструкция».

## Прочитать
- `docs/roadmap.md` («Готово, когда» каждого этапа), реестр требований (итог Э12-01), `docs/claude/perf-baseline.md`, отчёт Э12-02; решение «версия пока локальная» (лицензии: при выкладке заимствования переделываются отдельным этапом); навык `stalkerzone-dev` (доставка игроку).

## Шаги
1. Приёмочный чек-лист `docs/claude/acceptance-1.0.md`: собрать пункты «Чек-лист для игры» всех промптов в один маршрут по Зоне на 3–4 захода по 1–1,5 часа (юг, середина, север, системы: торговля, группа, выживание, выброс).
2. Заходы пользователя; каждое замечание — задача в карте с номером; блокирующие исправляются до сборки, остальные — в список «после 1.0».
3. Золотая копия мира: одна финальная пересборка со всеми журналами правок; контрольные суммы; проверка `chunkWrites=0`, `substitutions=0` после часа игры.
4. Комплект: jar мода, архив мира, список сторонних модов с версиями (TaCZ, Xaero, оптимизаторы, шейдер), локальные сборщики паков (звук, оружие) с инструкцией «что указать из своей копии игры», профили графики. Установка одной командой или инструментом (как в навыке).
5. Опись заимствований `docs/claude/borrowed.md`: что взято из TheZone, Anomaly, паков, оригинала — на случай публикации.
6. Документы: `00-start-here.md`, `05-handoff.md`, журнал решений — в состояние «1.0»; известные ограничения и отложенное (Э5-13, Э5-14, Э10-08, Э11-10, Э12-05) — отдельным разделом.
7. Метка версии в git и запись в карте «готово» вручную (задача без PR-заголовка — плейтест).

## Разрешённые файлы
`docs/claude/acceptance-1.0.md`, `borrowed.md`, документы передачи, инструменты доставки; код — только исправления блокирующих замечаний отдельными PR.

Пользователь прошёл все заходы и написал «принято»; чистая установка комплекта на его ноутбуке по инструкции занимает ≤ 15 минут; FPS и TPS не хуже базовой линии; аудит сходится после каждого захода.
