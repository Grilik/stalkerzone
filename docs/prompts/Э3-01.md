## Шаги
1. Разведка `javap -p` по jar из `mods` игрока (в git не копировать). Записать в `docs/claude/xaero-recon.md` с точными именами: конструктор `xaero.map.gui.GuiMap` (принимает ли родительский экран); поля или методы центра и масштаба текущего вида; есть ли публичная регистрация своих элементов карты (`MapElementRenderHandler`); создание и удаление набора путевых точек в Minimap; как называется папка карты мира в одиночной игре (по имени сохранения или по id) и где лежит; имена файлов настроек в `config/`.
2. `compat/XaeroMap.java`: `available()`, версии, `reflectFailed`; каждый найденный класс и метод — константой-строкой в одном месте (их читает тест). При старте — одна строка в лог: версии и «ok / запасной путь: причина».
3. `XaeroReflectTest`: все имена из п. 2 есть в jar. Путь к jar — из `-Dstalkerzone.xaero.dir`; нет jar (CI) — пропуск с пометкой, как TaCZ (P-20).
4. `mods.toml`: необязательные зависимости с точными версиями; при другой версии — предупреждение в лог и запасной путь, не падение.
5. Настройки по умолчанию для сборки (миникарта включена, путевые точки видны, набор «Зона» — по умолчанию) — файлы кладёт доставка, не мод; XaeroPlus из сборки убрать.
