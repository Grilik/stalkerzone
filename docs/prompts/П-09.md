# П-09: пульт базы — обзор, жители, сектора, склад, журнал

Автор: Fable, 16.11

**Исполнитель:** ведущий (Opus); снимок базы — карточка конвейера → `@sim-worker`
**Цель:** игрок видит живую базу как в ратуше MineColonies: кто чем занят, какие сектора работают и почему нет, что на складе, что случилось. Только просмотр.

## Шаги
1. Набросок экрана картинкой в PR — пользователь утверждает до кода.
2. Вкладки (вместо списка `04-interfaces.md`, с учётом отложенного):
   - **Обзор:** название, группа-владелец и фракция, лидер, люди / вместимость, касса группы, сплочённость и мораль, угрозы, укрытие (вместимость, идёт ли выброс).
   - **Жители:** именные из ростера — имя, роль, где и что делает; рядовые — числом по ролям и секторам (до реестра Э6-01 имён им не выдумывать). Клик по именному — подсветка NPC в мире на несколько секунд, если он материализован.
   - **Сектора** (вместо «Постройки»): здание → сектор, назначение, `staff/capacity`, работает или нет и причина (нет людей, нет сырья, нет входа). Уровней и «чего не хватает до уровня» нет — отложено.
   - **Склад:** запас группы по товарам, приход и расход за сутки, что привезли и что заказано; оценка в рублях — по `prices.json`. Еда — только привозная.
   - **Распорядок:** смены и чем занята база сейчас.
   - **Журнал:** последние события базы (кольцо ≤ 32).
3. Карточка `BaseSnapshotTest`: снимок строится только из данных группы и секторов; числа жителей сходятся с `members` группы на узле; сектор без людей — «не работает»; размер снимка ≤ 8 КБ.
4. Данные — по запросу: пакет «открыл пульт базы X», ответ и обновление раз в 2–5 с, пока экран открыт; в общий снимок КПК не включать.
5. Доступ: у блока «журнал старшего» на базе — всё; из КПК — для баз своей группы и фракции всё, для известных чужих (Э3-08) только «Обзор» без кассы и склада (**допущение**, туман войны).
6. Блок «журнал старшего»: поставить в штабе деревни новичков инструментом Э2-01 с журналом и превью пользователю (правка мира — по процедуре Э1-03); ПКМ открывает пульт.
7. Вкладка КПК «Отношения» → карточки группировок → группы → базы → пульт в режиме чтения.

## Проверка и приёмка
`BaseSnapshotTest` зелёный; числа в пульте совпадают с `/zone people` и отчётом узла; открытый пульт не роняет TPS (запрос ≤ 0,2 мс); чужая база из КПК не показывает склад.

## Видно в игре
ПКМ по журналу старшего в деревне новичков или КПК → «Отношения» → Одиночки → база: шесть вкладок с живыми числами, меняющимися со временем суток.

## Чек-лист для игры
- На базе: открыть пульт, сверить «Жители» с тем, что видно вокруг.
- Дождаться вечера — «Распорядок» сменился; после выброса — запись в «Журнале».
- Из КПК вдали от базы — тот же экран, только чтение.
