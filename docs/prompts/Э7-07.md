# Э7-07: карьера игрока — репутация, вступление, звания, скидки, изгнание

Автор: Fable, 16.11

**Исполнитель:** ведущий (Opus)
**Цель:** проверить и довести то, что уже есть в коде: игрок зарабатывает репутацию у групп, вступает, растёт в звании, получает скидки и доступ, а за предательство его изгоняют.

## Шаги
1. Ревизия кода (`@scout`): что из карьеры работает, что привязано к фракции вместо группы, где репутация пишется мимо одной точки входа. Итог — таблица «есть / частично / нет» в PR.
2. Репутация — у **группы** (фракция — среднее по её группам с весом): дела для группы (задания, спасённые, проданный хабар, убитые враги) и против (убийства, воровство со склада, нарушение перемирия).
3. Вступление: порог репутации + разговор с лидером группы или его заместителем (до Э8-06 — существующий способ); игрок наследует отношения группы; выход — добровольный, без штрафа, если нет долгов.
4. Звания (4–5 ступеней по вкладу): скидка у торговцев группы, доступ к складу (брать в пределах лимита — это реальные вещи со склада, учёт через `Ledger`), койка и укрытие на базах группы, право брать задания выше рангом. Пульт базы (П-09) — с высшей ступени, только просмотр и заказы, без «уровней».
5. Изгнание: убийство своего, кража сверх лимита, срыв перемирия → изгнан, репутация в минус, охрана баз группы враждебна; путь назад — через выкуп (деньги в кассу группы) и задания.
6. Скидки и наценки — множитель к цене `Prices` по репутации группы и личной памяти торговца; купил-продал не должен давать прибыль ни при каком звании (тест).
7. Сохранение карьеры — секция кодека по игроку (UUID). При сбросе симуляции карьера сбрасывается вместе с группами (допущение); записать это в `05-handoff.md`.

## Проверка и приёмка
Тесты зелёные: репутация меняется только через одну точку входа; вещи со склада по званию проходят через `Ledger`; арбитража нет при любой скидке; изгнанный игрок враждебен охране.

## Видно в игре
Помог одиночкам деревни — зовут в группу; вступил — у Сидоровича дешевле, на базе есть своя койка; выстрелил в своего — изгнали, у ворот встречают огнём.

## Чек-лист для игры
- Выполнить два задания группы, вступить, увидеть звание в КПК и скидку у торговца.
- Взять со склада группы патроны в пределах лимита.
- Убить своего — изгнание и враждебная охрана.
