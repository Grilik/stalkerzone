## Что изменилось в старых промптах
- **Постройки TheZone как есть** (решения 15.11): Э2-02/Э2-03 больше не «поставить сборщик в мир», а «назначить роль, найти границу базы, разложить сектора и места NPC в постройках TheZone». Сборщики `zonemap/build/*` — только для укреплений и недостающих мелочей.
- **Места — вручную по F3** (атлас Кордона, Э1-06), остальное — по пересчёту с подгонкой к рельефу.
- **Еда только привозная** (Э8-08): на Кордоне `farmCap` убрать до баланса главного цикла (Э2-09).
- **Выброс не отнимает точки**, отряды — в укрытия (Э2-18).
- **Группы** одиночек и банды — сразу (Э2-17).
- **Южный блокпост — ворота Зоны** (Э2-10, `border.json` → `south_gate`).

## Порядок
1. **Основа разметки:** Э1-14 (инструмент границ базы и раскладки секторов) → Э1-15 (правила аванпостов) → Э1-07 (пользователь утверждает роли мест Кордона на превью: базы, малые базы, аванпосты, поля, логова, укрытия). Э2-13 (словарь «материал → блок») — параллельно, нужен для укреплений.
2. **Места в атласе:** Э2-02, Э2-03 (роли, сектора, места NPC) → Э2-05 (узлы симуляции, точки NPC, аномалии, логова — из атласа; снимает выключатель Э2-20). Э2-01 — инструмент постановки, нужен для укреплений Э2-07.
3. **Жизнь Кордона** (симуляция — `@sim-worker` по тестам, мир — ведущий): Э2-17 (группы) → Э2-15 (живые базы: рабочие места, распорядок, производство) → Э2-18 (выброс и укрытия) → Э8-08 (еда только привозная) → Э2-06 (стая в мире).
4. **Укрепления и связность:** Э2-07 (крупные и малые аванпосты с укрытиями, постановка Э2-01 с журналом) → Э2-12 (тропы и дороги) → Э2-10 (граница, ворота на Южном блокпосте, лес за краем).
5. **Война и цикл:** Э2-08 (война на Кордоне) → Э2-09 (главный цикл, таблица звеньев).
6. **Приёмка:** Э2-11 — плейтест пользователя в опытной копии (свежий мод, ≈ 30–40 мин, список — как в `08-trial-copy.md`).

## Правила
- Каждая задача — свой PR с номером в заголовке; правки мира — только в рабочей копии через журнал, с превью «до/после» пользователю перед записью.
- Пользователю показывать: превью ролей (Э1-07), раскладку секторов (Э1-14), рендеры укреплений (Э2-07) и границы (Э2-10).
- После пунктов 2, 3 и 5 — обновить `TheZone-trial` и дать пользователю короткий заход.
