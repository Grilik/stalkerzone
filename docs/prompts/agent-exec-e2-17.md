## Объём (только это)
1. sim/Group.java — id строкой, фракция, лидер (Person из существующего ростера), главная база и узлы, склад, касса, members,
   параметры: агрессия, тяга к расширению, дисциплина, сплочённость, осторожность, мораль, влияние лидера.
2. sim/GroupRelations.java — разреженная таблица отклонений от отношений фракций; узлом владеет группа, владелец-фракция выводится.
3. sim/Faction.java — members равен сумме по группам каждый день.
4. sim/Politics.java — спор групп одной фракции снижает unity.
5. Состав групп Кордона в сценарии: вольные сталкеры (без группировки, хаб — деревня новичков);
   одиночки (основная база Свиноферма + зависимые: лагерь у вагончика, дыра в заборе, проводники);
   бандиты (конкурирующие банды, АТП и др.).
6. Сохранение — секция-хвост г-П8; сохранение без секции групп загружается, группы берутся из сценария.
7. Переход человека между группами — событие, без глобального реестра людей.
