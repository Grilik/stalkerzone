# 1.1 Аномалии, артефакты, выброс

| № | Действие | Ожидаемо |
|---|---|---|
| 1.1.1 | `/zone anomalies near`, дойти по координатам | частицы своего рисунка у каждого из 8 типов |
| 1.1.2 | Край Трамплина, Жарки, Электры в режиме выживания | подбрасывает, поджигает, бьёт током |
| 1.1.3 | Подождать у аномалии (или `/zone step 30`) | внутри появляется светящийся артефакт |
| 1.1.4 | `/zone emission` под крышей и на открытом месте | заголовок «ВЫБРОС», гроза; урон только под открытым небом |
| 1.1.5 | `/zone anomalies near` до и после выброса | аномалии сменили места |
