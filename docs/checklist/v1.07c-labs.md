# Лаборатории

| № | Действие | Ожидаемо |
|---|---|---|
| Л.1 | `/zone labs` | 5 лабораторий, сложность, прогресс, X-2 закрыта, пока работает Выжигатель |
| Л.2 | `/zone labtp 0` (Агропром) | бункер с жёлто-чёрной полосой, внутри шахта с лестницей вниз |
| Л.3 | Спуститься | комнаты с плиткой, коридоры, обвалы, паутина, часть ламп разбита, оборудование, бочки-тайники |
| Л.4 | Побыть внутри | появляются охранники (снорки, псы) не на глазах у игрока |
| Л.5 | ПКМ по терминалу без накопителя | «Нужна пустая флешка или диск» |
| Л.6 | ПКМ с флешкой | тревога, проценты скачивания над хотбаром, каждые 15 секунд новые враги |
| Л.7 | Отойти дальше 5 блоков во время скачивания | «Скачивание прервано» |
| Л.8 | Дождаться 100% | флешка светится, название «Флешка (данные …, терминал N)» |
| Л.9 | ПКМ по тому же терминалу | «Данные с этого терминала уже скачаны» |
| Л.10 | Флешка с данными, ПКМ по Сахарову на Янтаре (или «Сдать данные учёным» в КПК) | премия 3000 руб. за Агропром; в `/zone labs` выросли «изучено» и исследования |
| Л.11 | `/zone labtp 2` (X-16) без шлема | урон, тошнота, «Пси-излучение!»; два этажа |
| Л.12 | Там же в прототипе пси-шлема | урон почти нет, шлем изнашивается |
| Л.13 | X-10 с флешкой | «Нужен пустой переносной диск»; `/zone buy диск` |
| Л.14 | Скачать данные, затем `/zone monolithwin`, сдать данные | «Данные устарели»; терминалы снова полны, `/zone labs` показывает цикл 2 |
| Л.15 | Контракт «Данные лаборатории» | при сдаче данных этой лаборатории закрывается вместе с премией |
| Л.16 | `/zone step 300`, `/zone events 50` | фракции ходят в экспедиции, часть добывает данные и продаёт учёным |
