# 1.3 КПК

| № | Действие | Ожидаемо |
|---|---|---|
| 1.3.1 | ПКМ с КПК в руке (или `/zone pda`) | окно с вкладками «Карта», «Задания», «Новости», «Группировки», «Лаборатории» |
| 1.3.2 | Карта | точки цветом владельцев, дороги, зелёная точка «вы», аномалии, логова, синие квадраты лабораторий; подсказка при наведении |
| 1.3.3 | Колёсико или «+» на карте | карта приближается к вам, видны названия точек |
| 1.3.4 | Вкладка «Новости» | журнал Зоны, колёсико прокручивает |
| 1.3.5 | Вкладка «Группировки» | численность, раненые, лидер, фаза, опыт, стресс, единство, отношения |
| 1.3.6 | `/zone buy кпк` у торговца | КПК куплен |
| 1.3.7 | Открыть КПК, подождать, нажать «↻» | данные обновились, игра не на паузе |
