# 1.10 Снабжение, физические деньги, стройка руками NPC, контракт армии

- [ ] Сборка проходит; старый мир не падает (сохранение v8 заменяется свежим сценарием v9).
- [ ] Есть предмет «Стройматериалы», у торговцев он продаётся, весит 1,5 кг.
- [ ] `/zone logistics`: у точек видны склады, снабжённость и сепаратизм, в пути есть конвои.
- [ ] Через неделю игры: в отчёте контракт «действует», есть оплаты; у полевых баз армии в сейфах есть деньги.
- [ ] Новые точки «База военных «Агропром»» и «База военных «Янтарь»» появились на карте КПК и как лагеря армии.
- [ ] `/zone buildings`: у части построек есть строка «стройка до уровня N: материалы X/Y…», процент растёт.
- [ ] На точке со стройкой ходят строители, леса перерисовываются по мере готовности.

- [ ] `/zone construct military_base 1 3`: полевая база армии достраивается до укреплённой (вышки, прожекторы, колючка).
