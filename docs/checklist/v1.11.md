# 1.11 Облик, техника, радиация, рынок Большой земли

- [ ] Сборка проходит; в творческом меню есть шифер, побелка, ПО-2, краска кузовов, колёса, фары, ящики, радиоактивная бочка.
- [ ] Скаты шифера и кузовов правильно стыкуются в углах (внутренние и внешние углы).
- [ ] Стекло кабины прозрачное (вырез), колесо ставится осью как бревно.
- [ ] Текстурпак 64×64 включается из меню пакетов; без него блоки мода всё равно в 64×64.
- [ ] `/zone build vehicle_showcase 0`: вся техника в три ряда (целая, без стёкол и колёс, сгоревшая).
- [ ] `/zone build rookie_house 2`: белые стены, шиферная крыша, голубые ставни по бокам окон.
- [ ] `/zone build rail_bridge 2` на насыпи: устои, балки, блокпост наверху, машины под мостом.
- [ ] `/zone build atp 2`: забор ПО-2, автобусы, пожарная машина в боксе, бочки с отходами у забора.
- [ ] Рядом с брошенной машиной счётчик трещит, доза растёт; у бочки с отходами — быстро. В «Экологе» медленнее.
- [ ] Медикаменты (ПКМ) снимают дозу и лечат; при большой дозе голод, слабость, отравление.
- [ ] `/zone world`: цены Большой земли меняются день ото дня, бывают события, в пути есть заказы.
- [ ] Цены у торговцев следуют за Большой землёй (во время «дефицита медикаментов» медицина дороже).
- [ ] Старые сохранения (v9) начинаются заново (v10).
