# Э1-17: контейнеры мода вместо сундуков TheZone

Опытная копия TheZone-trial после правки рабочей копии (журнал Э1-03). Сборка — из PR Э1-17.

| № | Действие | Ожидаемо | Проверено |
|---|---|---|---|
| 1 | Деревня новичков и АТП: найти ящики (бывшие сундуки), посмотреть вид | деревянные/армейские/металлические ящики, шкафы — с текстурами, не фиолетово-чёрные, повёрнуты передом как были сундуки |  |
| 2 | Открыть ящик (ПКМ) | окно сундука на 1–3 ряда; внутри добыча (хлам, детали, патроны, медицина, консервы; рубли — редко); лишние ячейки не принимают предметы |  |
| 3 | Закрыть и открыть тот же ящик снова | содержимое то же — добыча не появляется заново |  |
| 4 | Шкафчик раздевалки (2 блока): открыть за верхнюю и за нижнюю половину; сломать одну половину | открывается одно и то же; ломается целиком, выпадает один шкафчик и содержимое |  |
| 5 | Сломать любой ящик и взять его в инвентарь | вес по листу: ящик 15–20 кг, металлический 30 кг, цинк 3 кг, шкаф 35–40 кг, сейф 120 кг |  |
| 6 | Выйти из мира, открыть `logs\latest.log` | нет ошибок про `stalkerzone:zone_container`, `LootTable`, `chests/box…`; `mode=THEZONE chunkWrites=0` |  |
