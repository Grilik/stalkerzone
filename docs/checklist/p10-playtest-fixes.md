# Ошибки плейтеста 05.11: вес патронов, рюкзак, сено (П-10)

| № | Действие | Ожидаемо |
|---|---|---|
| П10.1 | Взять стак патронов TaCZ 5,45×39 (60 шт.), посмотреть индикатор веса | стак весит меньше 1 кг (≈0,7), а не 210 кг |
| П10.2 | Взять ПМ, АК-74, СВД, коробку патронов | ПМ ≈1 кг, АК ≈3,5, СВД ≈4,5; коробка — тара 0,3 + патроны внутри |
| П10.3 | Умереть с вещами | на месте гибели стоит рюкзак (модель на земле, не крутится), в КПК — метка |
| П10.4 | ПКМ по рюкзаку | окно на 6 рядов «Рюкзак: <имя>», вещи можно брать по одной или кнопкой «Забрать всё» |
| П10.5 | Забрать всё и закрыть окно | рюкзак исчезает, метка в КПК пропадает; если инвентарь полон — остаток лежит в рюкзаке |
| П10.6 | Ударить рюкзак, взорвать рядом, налить воду, поджечь | рюкзак цел и стоит на месте; через 20 мин исчезает |
| П10.7 | Новый мир, крыша штаба Волка (18, −8) | на крыше нет блоков сена |
