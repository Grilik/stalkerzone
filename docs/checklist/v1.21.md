# 1.21 КПК Кордона (карточка 015)

| № | Действие | Ожидаемо |
|---|---|---|
| 1.21.1 | Взять КПК и ПКМ | открывается экран с вкладками «Карта», «Задания», «Новости», «Отношения», «Лаборатории»; карта ограничена Кордоном (X −83..605, Z −858..338) |
| 1.21.2 | Пройти деревня → мост → свиноферма, смотреть карту | подложка появляется по мере исследования (туман войны): цвет верхнего блока сеткой 4×4, неисхоженные места тёмные |
| 1.21.3 | Выйти из мира и зайти снова, открыть КПК | подложка на месте: файл `stalkerzone/pda_map_<мир>.png` в папке игры (`.minecraft`) |
| 1.21.4 | Навести на метки трёх проходов | туннель — оранжевая (средняя опасность), мост — зелёная с жёлтой рамкой (пошлина), дыра — красная (высокая); подсказка: владелец, цена, опасность |
| 1.21.5 | Найти бункер на карте | у бункера жёлтый маркер с подписью «Сидорович» |
| 1.21.6 | Смотреть карту после `/zone lairs` | известные логова мутантов отмечены красными точками, укрытия от выброса — голубыми |
| 1.21.7 | Взять контракт (вкладка «Задания») и открыть карту | цель взятого контракта обведена жёлтой рамкой, в списке есть кнопки «Взять», «Отказаться», «Сдать» |
| 1.21.8 | Вкладка «Новости» | тот же журнал, что выводит `/zone events` |
| 1.21.9 | Вкладка «Отношения» | репутация у Одиночек, Бандитов, Военных и Торговцев, ниже — отношения группировок и встречи лидеров |



| № | Действие | Ожидаемо |
|---|---|---|
| Ф.1 | `/zone step 500`, `/zone audit` | аудит сходится |
| Ф.2 | Выйти из мира и зайти снова | контракты, лидеры, лаборатории, раненые на месте (сохранение) |
| Ф.3 | Открыть мир, созданный до версии 1.8 | загружается, но карта сменилась: симуляция начинается заново, лучше создать новый мир |
