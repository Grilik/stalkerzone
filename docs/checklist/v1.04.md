# 1.4 Контракты

| № | Действие | Ожидаемо |
|---|---|---|
| 1.4.1 | КПК → «Задания» (или `/zone contracts`) | 3–12 контрактов: заказчик, сложность ★, награда (рубли и, может, товар), срок |
| 1.4.2 | «Взять» на контракте «Принести артефакты» | контракт ваш (жёлтый), на карте рамка у точки сдачи |
| 1.4.3 | Принести артефакты на точку сдачи, «Сдать» | артефакты списаны, награда в инвентаре; `/zone audit` сходится |
| 1.4.4 | Сдать вдали от точки | отказ «Сдать можно только на …» |
| 1.4.5 | Взять «Зачистить логово», перебить его мутантов | в момент уничтожения логова приходит награда |
| 1.4.6 | «Отказаться» | контракт снова открыт для всех |
| 1.4.7 | Взять 4-й контракт | отказ «Не больше 3 контрактов» |
| 1.4.8 | `/zone step 10`, `/zone events 30` | Одиночки сами выполняют часть контрактов |
