# Чек-лист проверки в игре

Как пользоваться: создайте **новый** мир типа «Зона» с читами. Проверяйте по порядку, отмечайте ✅ или ❌. При ❌ пришлите номер пункта и что видели (скриншот или строку из лога `logs/latest.log`).

Ускорители: `/zone step <дней>` проматывает симуляцию, `/zone tp <локация>` переносит к точке, `/gamemode creative` даёт творческий режим, вкладка «Зона» в творческом меню содержит все предметы мода. Один день симуляции длится 5 минут игрового времени.

## Как устроено (П-06, 05.11.2026)

Один файл на задачу или версию — PR друг другу не мешают (раньше все дописывали раздел в конец одного `CHECKLIST.md` и конфликтовали).

- **Новая задача — новый файл** `docs/checklist/<задача>.md`: карточка — `NNN-<имя карточки>.md` (как в `docs/tasks/`), задача рабочих чатов — `p<номер>-<коротко>.md` (например `p02v-fence-trapdoor.md`). Первая строка — заголовок `# Название (задача)`, дальше таблица `| № | Действие | Ожидаемо |`, номера пунктов с префиксом задачи (`033.1`, `П02в.2`).
- Чужие файлы чек-листа и `CHECKLIST.md` не правь. Дополнение к сделанной задаче — в её файл.
- Весь чек-лист одним файлом (для тестера, печати): `python3 tools/checklist.py > CHECKLIST_ALL.md` — версии, потом карточки, потом задачи рабочих чатов.
- Проверка: `ChecklistTest` (CI) — в `CHECKLIST.md` нет пунктов, у каждого файла здесь есть заголовок и хотя бы один пункт.
