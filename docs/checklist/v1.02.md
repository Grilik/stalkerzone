# 1.2 Сила аномалий, инвентарь, вес, снаряжение, износ, мутанты в мире

| № | Действие | Ожидаемо |
|---|---|---|
| 1.2.1 | Аномалии у Кордона и у Радара | у Радара урон выше, анимация гуще |
| 1.2.2 | Инвентарь (E) в режиме выживания | открыт хотбар и один ряд, остальное заглушки, строка веса над окном |
| 1.2.3 | Взять 2 стака деталей | индикатор веса оранжевый, скорость упала; при сильном перегрузе нельзя бежать и прыгать |

| 1.2.6 | Походить в костюме у Жарки | состояние падает, урон растёт |
| 1.2.7 | `/zone repair` с костюмом в руке у торговца | состояние 100%, рубли списаны |
