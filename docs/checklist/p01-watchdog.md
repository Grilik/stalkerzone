# Зависание мира и сторож серверного потока (П-01)

| № | Действие | Ожидаемо |
|---|---|---|
| П01.1 | Новый мир, войти | в `logs/latest.log` строка `[stalkerzone] сторож серверного потока включён` |
| П01.2 | Играть как раньше: деревня, дорога на север к элеватору, 10–15 минут | мир не замирает; если замер — подождать 30 с, выйти и прислать `logs/latest.log` (в нём будет `[stalkerzone] СТОРОЖ: сервер не тикает … Стек серверного потока`) |
| П01.3 | Пауза (Esc) на минуту | строк `СТОРОЖ` в логе нет — пауза не считается зависанием |
| П01.4 | Отключение: `config/stalkerzone/compat.json`, `"watchdog": false`, перезапуск | строка `сторож серверного потока выключен` |
