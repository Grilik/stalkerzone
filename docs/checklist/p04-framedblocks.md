# FramedBlocks — необязательная зависимость (П-04)

| № | Действие | Ожидаемо |
|---|---|---|
| П04.1 | `C:\MineStalker\stalker_tools\modpack.bat`, потом положить `FramedBlocks-9.4.3.jar` из `C:\MineStalker\modpack\mods` в `mods` игры вместе с новым `stalkerzone` из `nightly` | игра запускается, в списке модов есть FramedBlocks |
| П04.2 | Новый мир с FramedBlocks | мир создаётся, деревня и бункер на месте, игра не зависает при загрузке чанков |
| П04.3 | Убрать `FramedBlocks-*.jar` из `mods`, новый мир | мод работает и без него (крыши и откосы будущих построек — ванильными ступенями и плитами) |
| П04.4 | С FramedBlocks: творческий режим, поставить «Framed Slope» и кликнуть по нему блоком шифера мода | скат принимает текстуру шифера (проверка, что камуфляж работает с блоками мода) |
