# Наброски интерфейсов «Малого Кордона»

Перед кодом каждого окна — набросок на утверждение (спецификация — документ проекта `claude/04-interfaces.md`).

| Задача | Набросок | Что показывает |
|---|---|---|
| П-07 | `p07-trader.png` | окно торговца: товары торговца слева, ваш рюкзак с ценой выкупа справа, сделка (1 / 10 / всё, итог), касса и деньги; вкладки «Заказы и контракты», «Ремонт» |
| П-08 | `p08-pda-map.png` | карта КПК: рельеф всего Кордона, базы и заставы, отряды в пути с маршрутом и подсказкой, аномальная зона, логово, укрытия, вы, ваш рюкзак, цель контракта, бой; карточка узла и слои |
| П-09 | `p09-base-panel.png` | пульт базы (журнал старшего): сводка, жители (роль, где и что делает, здоровье), карточка жителя с «подсветить в мире»; вкладки обзор, постройки, склад, распорядок, журнал |
