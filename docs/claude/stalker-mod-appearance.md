# Stalker Zone: внешность, травмы, имена (v0.2)

## Как это работает
1. **Геном.** При появлении агента ядро вызывает `AppearanceGenerator.generate(seed, фракция, роль, ранг, пол, возраст)`. Получается `Appearance`: тон кожи, глаза и их цвет, брови, причёска и цвет волос, борода, морщины, шрамы и татуировки, покрой и цвет одежды, головной убор, грязь, снаряжение. Генератор детерминирован: тот же seed даёт то же лицо.
2. **Скин.** `Appearance.layers()` возвращает слои по порядку. На клиенте `SkinCompositor` складывает их в одну текстуру (серые слои волос, бровей и радужки окрашиваются), кэширует 256 скинов и собирает не больше 4 за тик. Пока скин не готов, рисуется запасной скин фракции.
3. **Объём.** `StalkerGearLayer` рисует снаряжение отдельными моделями на костях NPC: рюкзаки, разгрузки, каски, противогазы, гипс, шину, костыль, объёмные причёски и бороду. Поза копируется каждый кадр, так что рюкзак двигается вместе с телом. Поверх надетой брони головные и нагрудные предметы не рисуются.
4. **Травмы.** Ядро добавляет `InjuryVisual` (`withInjury`) и снимает при лечении (`healed`). Зажившая травма может оставить шрам или перейти в постоянное состояние.
5. **Имена.** `NameGenerator` выдаёт имя, отчество, фамилию, город, прошлую профессию и кличку. `NameRegistry` гарантирует уникальность в мире (хранить вместе с данными ядра).

## Подключение к существующему NPC
```java
// сущность (общая сторона)
private static final EntityDataAccessor<String> DATA_LOOK =
        SynchedEntityData.defineId(StalkerEntity.class, EntityDataSerializers.STRING);
// defineSynchedData: entityData.define(DATA_LOOK, "");
// при создании: entityData.set(DATA_LOOK, appearance.encode());  NBT: putString("Look", ...)

public class StalkerEntity extends PathfinderMob implements AppearanceHolder {
    private String lookKey = ""; private Appearance look;
    @Override public Appearance appearance() {
        String s = entityData.get(DATA_LOOK);
        if (!s.equals(lookKey)) { lookKey = s; look = s.isEmpty() ? null : Appearance.decode(s); }
        return look;
    }
}

// клиент
public class StalkerRenderer extends AbstractStalkerRenderer<StalkerEntity> {
    public StalkerRenderer(EntityRendererProvider.Context ctx) { super(ctx); }
    @Override protected String factionId(StalkerEntity e) { return e.factionId(); }
}
```
`AppearanceClientEvents` сам регистрирует геометрию снаряжения и сброс кэша по F3+T. Броня мода (`stalkerzone:<комплект>`) рисуется стандартным слоем брони поверх скина, как раньше.

## Снаряжение (36 предметов)
Спина: ранец, рейдовый рюкзак с ковриком, экспедиционный на раме (канистра, котелок), вещмешок, сумка медика, рация с антенной, контейнер для артефактов. Грудь и пояс: разгрузка, бронежилет, патронташ, сумка через плечо, пояс с подсумками и флягой. Ноги и руки: кобура, нож, наколенники, наплечники, дозиметр. Голова: кепка, восьмиклинка, берет, каска, противогаз, респиратор, налобный фонарь, гарнитура, шлем учёного (стекло). Волосы: хвост, вихры, длинные, длинная борода. Травмы: гипс, перевязь, шины, костыль.
Тканевые предметы есть в 9 палитрах: olive, khaki, black, brown, green, blue, gray, orange, white. Набор зависит от фракции, роли (медик, радист, охотник за артефактами, снабженец, техник, лидер) и ранга (новички беднее).

## Имена и клички
- Военные: звание + фамилия. Учёные: имя-отчество. Монолит: «брат Имя». Им клички не выдаются.
- Новичок получает кличку в 40% случаев, остальные позже за события: `NameGenerator.earn(name, фракция, NicknameEvent, seed)` (потерял глаз, обгорел, захромал, пережил выброс, нашёл редкий артефакт и т.д.).
- Кличка подбирается по внешности (рыжий, седой, лысый, борода, шрам, повязка, хромота), роли, фракции, характеру (`traits`: brave, cautious, quiet, cheerful, greedy, fanatic, lucky, coward, drinker), городу и прошлой профессии. Пожилым иногда «Дядя Имя» / «Дед Имя».
- Когда «говорящие» клички заняты, генератор собирает прилагательное + существительное с согласованием рода («Хмурый Барсук», «Тихая Гайка»). Имена сюжетных персонажей S.T.A.L.K.E.R. не выдаются.
- Форматы: `kpkName()` Тарас «Гвоздь» Мельник, `shortName()` над головой, `formal()`, `military(звание)`, `scientist()`, `monolith()`, `bio()` для КПК.

## Проверка
`java/src/test/.../AppearanceSelfTest` на 5000 агентов: 99,98% уникальных скинов, 98,7% уникальных лиц (без учёта одежды), все клички и полные имена уникальны, сериализация туда-обратно, все 246 задействованных текстур на месте, лечение снимает все непостоянные травмы.
```
javac --release 17 -encoding UTF-8 -d out java/src/main/java/ru/stalkerzone/appearance/*.java java/src/test/java/ru/stalkerzone/appearance/*.java
java -Dfile.encoding=UTF-8 -cp out ru.stalkerzone.appearance.AppearanceSelfTest assets/stalkerzone 5000
```
**Важно.** Клиентские классы Forge проверены только компиляцией против заглушек с сигнатурами API 1.20.1, а не настоящим Forge: при первой сборке возможны мелкие правки имён методов.

## Как править
Генераторы в `tools/`: `gen_layers.py` (слои скина), `gen_gear.py` (геометрия и текстуры снаряжения, единый источник), `gen_java.py` (перегенерирует `GearType` и `GearModels` из `gear_spec.json`), `render_agents.py` (3D-превью). Порядок: `gen_layers.py`, `gen_gear.py`, `gen_java.py`. Текстуры можно доводить вручную в Aseprite/Blockbench поверх сгенерированных, раскладка UV стандартная.
