# Макет всей карты (v1.15–v1.17)

## v1.15 (0c306ee): 11 уровней ТЧ
- Уровни ТЧ 1:1 (.szl) по глобальной карте игры, промежуток ≥170 блоков, Кордон на месте (деревня новичков ≈ 0,0).
- Файлы: `<папка игры>/stalkerzone/levels/*.szl` + `layout.json`. В репозиторий не кладутся (данные GSC).

- Болота (k00_marsh), Тёмная лощина (k01_darkscape), Свалка техники (k02_trucks_cemetery), Мёртвый город (l09_deadcity), Рыжий лес (l10_red_forest), Лиманск (l10_limansk), Госпиталь (l11_hospital).
