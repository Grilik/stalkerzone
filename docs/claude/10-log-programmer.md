### Инструкция «Строителю»: формы FramedBlocks в сборщике (для П-05)
```java
import ru.stalkerzone.zonemap.build.Framed;
b.set(x, y, z, Framed.slope("stalkerzone:zm_shifer", "north", false));          // скат, высокая сторона на север
b.set(x, y, z, Framed.cornerSlope("stalkerzone:zm_shifer", "east", false));     // внешний угол (вальма)
b.set(x, y, z, Framed.innerCornerSlope("stalkerzone:zm_shifer", "west", false)); // внутренний угол (ендова)
b.set(x, y, z, Framed.slab("minecraft:spruce_planks", true));                   // плита сверху
b.set(x, y, z, Framed.panel("stalkerzone:zm_planks_gray", "south"));             // панель у южной стороны (рама)
b.set(x, y, z, Framed.of(Framed.Shape.WALL_BOARD, "minecraft:dark_oak_planks", "north", false)); // наличник
b.set(x, y, z, Framed.of(Framed.Shape.PILLAR, "minecraft:oak_log[axis=y]", "y", false));         // столб
```
- Формы (`Framed.Shape`): `SLOPE`, `CORNER_SLOPE`, `INNER_CORNER_SLOPE`, `STAIRS`, `SLAB`, `SLAB_EDGE`, `PANEL`, `FLOOR_BOARD`, `WALL_BOARD`, `PILLAR`, `CUBE`. `facing` — north/south/west/east (у `PILLAR` — x/y/z); `top` — верхняя половина клетки или перевёрнутый скат. Камуфляж — любой полный блок, можно с состоянием.
- **Без FramedBlocks** то же самое ставит запасной вариант: скаты и углы → ступени материала (`zm_*_stairs`, ванильные — по таблице; если ступеней нет — полный блок), плиты и доски на полу → плита, панель/столб/куб → полный блок, доска на стену → ничего. Сборщик ничего не проверяет сам.
- **Превью** (`tools/prefab/preview.sh`) получает строку с `{camo:…}`: состояние до `{` — `Framed.split(s)[0]`, текстура — из камуфляжа. При `Framed.loaded = false` (по умолчанию в превью) там будут ванильные ступени — удобно для «до/после».
- Ставить framed-блоки только через `BlockSink.set` сборщика (генерация кладёт NBT сама, `ZoneMapPlacer.applyNbt`).
