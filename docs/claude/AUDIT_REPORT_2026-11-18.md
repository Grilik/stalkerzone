## Главный источник, который должен быть главным для каждого вида данных

| Тип данных | Должен быть главным | Сейчас |
|------------|---------------------|--------|
| Требования проекта | requirements.json в git (132 шт) | ❌ Несовместим с requirements.md на ПК (201 шт) |
| Задачи roadmap | docs/roadmap.md (165 задач) | ❌ Статусы только для ~10; нет связи с требованиями |
| Прогресс Qwen | docs/qwen/progress.md | ❌ **На main рассинхронизирован с qwen/pilot** |
| Статусы тестов | Git commits + CI (build.yml) | ⚠️ Автоматический, но не привязан к requirements |
| Статусы задач roadmap | Pull Request titles (начинаются с Э-номера) | ⚠️ Хорошо, но требует ручного парсинга |
| Одобрение приёмки | Плейтесты (пользователь) | ❌ Записываются в comments PR, не в requirements.json |

## Какие статусы должны существовать

Предлагаемые 9 статусов:

1. **PLANNED** — запланирована, задача в roadmap
2. **IN_PROGRESS** — выполняется, PR открыт или локальная разработка
3. **CODE_COMPLETE** — код написан, PR готов к review
4. **TESTS_PASSED** — автотесты пройдены (CI зелёный)
5. **GAME_VERIFIED** — проверена в Minecraft (плейтест или лог)
6. **ACCEPTED** — принята пользователем / штабом
7. **BLOCKED** — заблокирована, есть причина
8. **DEFERRED** — отложена (отличается от BLOCKED, может быть возобновлена)
9. **REJECTED** — отклонена

**Текущее состояние:** только DONE_TESTED, DONE_UNVERIFIED, PARTIAL, MISSING, BLOCKED, DOCUMENTED_ONLY, DEFERRED — не полно соответствуют жизненному циклу задачи.

## Риски при внедрении

1. **Миграция от трёх источников к одному:** требует ручного приведения 132 требований и 165 задач в соответствие. Первый проход — черновой (найти дублики, разделить перекрытия).

2. **PR #204 в черновике:** тесты К1/К15/К16 остаются незалиты, progress.md на main остаётся неверным. Риск: разработка дальше идёт на устаревших данных.

3. **Локальная документация на ПК:** если её не завести в git, она расходиться может снова.

4. **Dashboard parsing:** если поле имя или структура поменяется, dashboard сломается. Нужна валидация schema.
