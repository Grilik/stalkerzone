### Как добавить сборщик в площадку (для «Строителя», из PR #64)
1. Класс в `zonemap/build/` как раньше: `public static final List<int[]> CLEAR` и `static void build(BlockSink b, int lvl)`.
2. В `Prefabs.SITES` у нужной площадки дописать `.build(of(X.CLEAR, X::build))` (деревня — `new Site("village", NODE_VILLAGE)`; бункер — `new Site("bunker", NODE_BUNKER)`, место торговца `duty` остаётся узлу 1). Новая площадка — `new Site(id, узел).plateau(x0, z0, x1, z1, Site.AUTO, откос).build(...)`.
3. `b.ground(x, z)` — верхний блок уже ровной земли, пол на `ground + 1`. Рабочие места — `b.mark(kind, x, ground + 1, z)` (`guard`, `patrol`, `bed`, `rest`, `cook`, `work`, `duty`, `gate`); NPC берут только места своей площадки. У деревни пока временные места из `Prefabs.villagePoints` — при постройке домов заменить своими.
4. Проверка: `SiteTest`, `PrefabsTest`, превью рельефа `bash tools/prefab/site.sh <szl> <png>`, построек — `tools/prefab/preview.sh` (без `.szl`: `flat:84`). Синтетический уровень: `python3 -I tools/xray/fake_szl.py /tmp/fake.szl`.
