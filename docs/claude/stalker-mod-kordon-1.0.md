# Кордон 1.0 — играбельный вертикальный срез (решение от 30.10.2026)

Сначала одна локация, Кордон, полностью играбельная со всеми системами. Остальные локации и группировки на это время выключены конфигом, код остаётся.

**Уровень:** Кордон из мода Last Emission (вариант 1) — прогоняем через наш конвейер `tools/xray`; нужны файлы мода на ПК пользователя. Раскладка — по карте Last Emission с правками пользователя.

Карта-схема (v4): https://claude.ai/artifact/6o79Fxchqp4YzTU8Fqijbi

## Принципы размещения
- **Базы** — главные точки группировок.
- **Мини-базы** — функциональные точки (элеватор, руины дома).
- **Заставы** — только у выходов на другие локации, у аномальных зон и на контроле дорог/территорий.
- Костры и стоянки — заставы контроля дорог/выходов.

## Базы и мини-базы
| Объект | Владелец | Функции |
|---|---|---|
| КПП военных (юг, конец дороги) | Военные, главная | казарма, склад, БТР, досмотр; за КПП Большая земля (не локация), оттуда новички и дезертиры |
| Деревня новичков (юго-запад) | Одиночки, главная | казарма, медпункт, мастерская, доска контрактов |
| Бункер Сидоровича (за деревней, как в каноне) | Торговцы | торговля, скупка, курьеры, наценка по группировке |
| АТП (юго-восток) | Бандиты, главная | гараж, склад награбленного, скупщик краденого |
| Ферма (сразу за насыпью) | Одиночки | еда, перевалочный пункт, малый медпункт |
| Элеватор — мини-база | ничья | зерно (еда), снайперская вышка |
| Руины дома — мини-база | ничья | укрытие от выброса, полевой медпункт |

## Аномальные зоны
A1 туннель (электры), A2 «Собачка» (поле, главная за артефактами), A3 сошедший состав (радиация), A4 холм мертвеца, A5 россыпь камней (учебная), A6 свалка техники (радиация, хабар в остовах).

## Логова
| Логово | Мутанты |
|---|---|
| Л1 лес на северо-западе | тушканы |
| Л2 засыпанный туннель (северо-восток, вместо северного выхода в ТД) | сильные: псевдособаки, редко кровосос; туннель снова «выпускает» после зачистки |

| Л5 за россыпью камней, не впритык | кабаны |

## Выходы
Свалка (О1; тропа через О2), Болота ×3 (О3 бывший проход в пещеры, О4 за насыпью, О5), Тёмная лощина (от АТП через О6). Прохода на Д-3 и северного выхода в Тёмную долину нет.
