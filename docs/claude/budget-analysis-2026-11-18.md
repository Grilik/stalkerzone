## Выводы

### 1. Бюджет НЕ проблема

Бюджета $27.76 хватает на:
- **100% проекта** на любой модели
- **85–89% остаётся** на переделки и эксперименты
- **6–8× запас** по количеству задач

### 2. Fable = Sonnet по цене

- Старое ограничение не актуально
- Можно использовать Fable вместо Sonnet БЕЗ доплаты
- Opus всего на 34% дороже Fable/Sonnet

### 3. Реальная проблема — качество на задачу

Вопрос не в деньгах, а в том:
- Насколько качественно модель решает задачу
- Сколько итераций нужно на правку
- Какие задачи требуют архитектурного мышления

### 4. Что проверить

✅ Запущены тестовые агенты:
- **@scout (Haiku)** — простой поиск
- **@architect (Fable)** — архитектурное решение

После результатов решить:
- Fable ≈ Opus? → Fable ведущим
- Fable < Opus? → Opus ведущим, Fable на рутину
