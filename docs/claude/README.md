# docs/claude — копия документов проекта

Копия документов Project «Мод на сталкер для майнкрафт» на claude.ai (папка `claude/`), чтобы любой Claude со свежим клоном репозитория знал состояние проекта без доступа к Project (П-12, план — `05-handoff.md`).

- **Начинать с `00-start-here.md`**: текущее состояние, журнал решений, открытые проблемы, запросы между чатами.
- Роли и очередь задач — `02-prompts.md`; журналы чатов — `10-log-programmer.md`, `11-log-builder.md`.
- Модель участка — `01-malyi-kordon.md`; интерфейсы — `04-interfaces.md`; передача — `05-handoff.md`; конвейер — `06-conveyor-v2.md`.
- `stalker-mod-*.md` — справочники (дизайн, лор, облик, логистика, бой, карта). Архивные документы Project сюда не копируются.
- Навык со сборкой, тестами и сервером — `.claude/skills/stalkerzone-dev/SKILL.md`.

**Синхронизация.** Если Project доступен — главный он: «Программист» в начале каждой сессии сверяет эту папку с Project и коммитит разницу вместе со своей задачей. Если Project недоступен — главные документы здесь, правки вносятся прямо в эти файлы. Кто какой файл ведёт: `00`, `01`, `02` — штаб; `10` — «Программист»; `11` — «Строитель».

Данные игры GSC (`*.szl`, извлечённые файлы) сюда и в репозиторий не класть.
