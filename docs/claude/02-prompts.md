Рабочие чаты (Claude Code с репозиторием `Grilik/stalkerzone`, навык `stalkerzone-dev`) открываются ролевым промптом («Строитель» или «Программист», ниже), берут задачи своей линии и в конце отчитываются в своём журнале (`10-log-programmer.md` / `11-log-builder.md`).
