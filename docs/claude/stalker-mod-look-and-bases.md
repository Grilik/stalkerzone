# Облик как в оригинале и функциональные базы (с 29.10.2026)

## Решения пользователя
- Текстуры: свои в моде + личный ресурспак с текстурами из его копии ТЧ (не публикуется).
- Здания: шаблоны по оригиналу (форма и размер как в игре, нормальные крыши/окна/двери/мебель), а не кубики 1:1.
- Порядок: сначала облик Кордона (образец), затем функции баз.
- Требование: все здания функциональны, как в MineColonies: медпункт, мастерская, полигон, казарма и т.д.; число слотов зависит от размера базы; здания улучшаются.

## Сделано (v1.17, d02a551)
- 60 материалов Зоны (tools/zone_blocks/materials.py → gen.py): блок+ступени+плита, щиты/ограды/панели/двери.
- Личный пак: tools/xray/make_pack.py из 169 текстур ТЧ (вырезка stalker_tools/tex_cut.bat) → `<игра>/stalkerzone/original_textures.zip`, мод подключает сам (всегда включён).
- Воксели уровней: текстуры игры → блоки Зоны (geo2cform: id 128+индекс материала; категории как запасной вариант).
- Кордон: 13 домов и 40 заборов по шаблону (extract.py → l01_escape.bld.json; HouseBuilder): стены из серых досок с угловыми столбами, цоколь, пол, окна с рамами, зелёная дверь, двускатная шиферная крыша ступенями, фронтоны, труба; крыша целая/дырявая/стропила по целости в игре; дощатые заборы щитами со столбами.
- Превью мира без клиента: tools/xray/mca.py + render.py/render_tex.py.
