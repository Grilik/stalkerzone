## Как пользоваться
- Этап — заголовок `## Э<N> · <название>`, под ним строка `Цель: …` и таблица задач.
- Колонка «статус» обычно **пустая**: страница ставит её сама по GitHub. Задача «готово», когда слит PR, заголовок которого начинается с её номера (`Э0-10: …`, `Т-01: …`, `058: …`). «В работе» — пока такой PR открыт. Иначе «ждёт».
- Вручную пишем только `отложено`, `снято` или `готово` (если задача сделана без PR, например плейтест).
- Новая задача — новая строка с новым номером. Номер — в начале заголовка PR. Это правило для всех: штаба, Claude Code, конвейера.
