# 038. Свиноферма по оригиналу

**Линия: мир.** **Модель исполнителя: сильная.** После 035.

Собрать постройки узла по обмерам оригинала вместо «куч вокселей» — метод в `docs/kordon_objects/README.md`,
обмеры — `docs/kordon_objects/10-farm.md`, образец кода — `zonemap/build/KordonSouthPost.java`.

## Что сделать
Длинные корпуса свинарников (двускатные крыши вдоль длинной оси, ворота в торцах, окна под крышей), подсобки, загоны.
Ферма должна выглядеть **рабочей** на уровне 1+ (плейтест: «ферма не функциональна»): кормушки, загоны с изгородью, сено, телега.
Рабочие места: `work` у загонов, `bed`, `cook`, `guard`.

## Готово, когда
- `bash tools/conveyor/check.sh` зелёный; `PrefabsTest` проверяет новый сборщик; статус карточки обновлён; пункт в `CHECKLIST.md`
  («Свиноферма — постройки ровные, с входами и крышами, на тех же местах»).
