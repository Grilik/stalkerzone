# 032. Роли и распорядок NPC базы (как в MineColonies)

**Линия: мир.** **Модель исполнителя: сильная.** После 031.

Цель: на базе не «бездумно бродят», а живут: часовые на вышках со сменой, патруль по периметру, повар у костра, механик у техники,
вечером ужин у костра, ночью сон в казарме.

## Что сделать
1. Роль NPC базы (поле в `StalkerEntity`, сохраняется в NBT): `GUARD`, `PATROL`, `COOK`, `MECHANIC`, `DUTY`, `RESIDENT`
   (существующие `ROLE_TRADER/BUILDER/HERMIT` не трогать). Распределение при появлении по свободным рабочим местам узла
   (031): сначала все `guard` (но не больше половины людей), 1–2 `PATROL`, 1 `COOK`, 1 `DUTY`, остальные `RESIDENT`/`MECHANIC`.
2. Новая цель `WorkScheduleGoal` (приоритет между боем и прогулкой — вместо `WaterAvoidingRandomStrollGoal` для NPC базы):
   по времени суток мира (`level.getDayTime() % 24000`):
   - день (≈ 6:00–18:00): идти на своё место и работать — часовой стоит на площадке, смотрит по сектору; патруль обходит
     `patrol` по кругу с паузами; повар у `cook`; дежурный у `duty`; механик у `work`; житель — между `rest`, `cook` и `work`;
   - вечер (18:00–22:00): все кроме часовых — у костра (места вокруг `cook`/`rest`, не в огне — правило 028);
   - ночь (22:00–6:00): все кроме часовых — у своего `bed` (стоят/сидят, не ходят); часовые — смена: половина `guard` ночью,
     половина днём (по чётности id).
   Бой (`TacticalCombatGoal`) прерывает работу; после боя — возврат на место.
3. Подпись над головой при взгляде (как у торговца, коротко): «Часовой», «Патруль», «Повар»… — только когда игрок близко.
4. Пункты в `CHECKLIST.md`: днём на всех трёх вышках блокпоста по часовому, патруль обходит периметр, ночью люди у нар.

## Готово, когда
- Сборка и тесты зелёные; распределение ролей — юнит-тест на чистой части (класс без Minecraft: «точки + число людей → роли»).
