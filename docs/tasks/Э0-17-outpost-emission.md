# Заставы одиночек не теряются при выбросе

**Конвейер:** да
**Тест:** `docs/tasks/tests/OutpostEmissionTest.java`
**Файлы:** `src/main/java/ru/stalkerzone/sim/Simulation.java`
**Чек-лист:** нет

Задача Э0-17 дорожной карты (`docs/prompts/Э0-17.md`, решение D6). Запускать вручную **после слияния Э0-14a**: Actions → conveyor, `card` = `Э0-17`.
Видно в игре косвенно: заставы одиночек на Кордоне не пустеют после выброса.

## Сейчас
`Simulation.emission()`: для каждой фракции с малым гарнизоном узлы теряются с вероятностью `p` («территорию заняли мутанты»). Исключение есть только для военных: `if (f.military && n.type == NodeType.OUTPOST) continue;`. Поэтому на Кордоне выброс отнимает у одиночек элеватор (4) и заставы 19, 20, 22, 23.

## Что сделать
В том же цикле `emission()`: в сценарии `"kordon"` (не `"kordon_war"`) узлы одиночек (`ZoneScenario.LONERS`) типа `OUTPOST` и `ANOMALY` выбросом не теряются — по аналогии с условием для военных. Гибель людей, зомби, логова и другие сценарии не менять.

## Готово, когда
`OutpostEmissionTest` зелёный, `bash tools/conveyor/check.sh` зелёный (`kordon_war` без изменений — `CrossingsTest` и остальные).
