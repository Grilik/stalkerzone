# 004. Мир Кордона: уровень из Anomaly с правками канона

**Исполнитель: Claude (архитектор).** В Cline не запускать: нужны файлы игры с ПК и конвейер `tools/xray`.
Заменяет прежнюю «обрезку фоновых заглушек ТЧ».

## Что нужно от игрока
- ПК включён и привязан к чату с Claude (Claude desktop app открыт).
- Установленная S.T.A.L.K.E.R. Anomaly 1.5.x (та же, из которой брались Болота и Тёмная лощина).

## Что сделать
1. Взять Кордон из Anomaly (`db/levels/level_l01_escape.db0`), вырезать нужные файлы через `cut.bat` / `converter.exe`,
   `remap.py` (материалы Anomaly → id ТЧ), импорт конвейером `tools/xray` в `kordon.szl` — как Болота и Тёмную лощину (README `tools/xray`, раздел «Уровни из Anomaly»).
   Уровень Anomaly заменяет прежний Кордон ТЧ 1:1; стыки с Болотами и Тёмной лощиной пересчитать (`layout2`, `links2`).
2. Правки канона: оставить выходы на Болота (запад), в Тёмную лощину (восток) и на Свалку (север); лишние проходы закрыть рельефом/забором;
   бункер Сидоровича — за деревней новичков, как в ТЧ; невидимые стены (материал 80) и фоновые «декорации за забором» не ставить.
3. Граница мира — по реальному краю уровня (`ZoneBounds` для сценария `kordon`), забор + барьер.
4. Файл точек `src/main/resources/data/stalkerzone/kordon_points.json` (координаты Minecraft, не данные игры):
   для каждого узла сценария — `center`, `campfire`, `beds[]`, `guards[]`, `flag`, `trader` (если есть), `shelter[]` (укрытия от выброса),
   `patrol[]`; для проходов — `gate` (бокс входа), маршрутные точки дорог `roads{узел→узел: [точки]}`; `spawn` игрока.
5. Уточнить координаты узлов в `KordonScenario` по точкам (`center` / 10).
6. Положить `kordon.szl` на ПК игрока в `stalkerzone\levels` и в облачный `run/stalkerzone/levels`.

## Готово, когда
- Сервер с `level-type=stalkerzone:zone` и сценарием `kordon` грузит Кордон без зависаний; узнаются деревня, АТП, элеватор, мост, ж/д насыпь, туннель, ферма, блокпосты.
- Нет фантомных построек и дорог в никуда; выход на Д-3 закрыт.
- `kordon_points.json` в репозитории; `.szl` — нет (в .gitignore).
