**Видно в игре:** после обновления мода мир пользователя загружается с прежней историей, а не сбрасывается

## Что сделать
Сохранение — набор секций `[имя, версия, длина, байты]`. Незнакомая секция пропускается по длине; отсутствующая заполняется из сценария и атласа. Перечисления пишутся и читаются по имени, не по номеру. Ссылки на узлы, сектора, группы — строковые id атласа. Секция-хвост этапа 2 (v24: группы, сектора, укрытия) читается как набор секций без потерь.

## Готово, когда
Незнакомая секция пропущена, остальное прочитано; эталонные сохранения v23 и v24 `kordon` (в `src/test/resources/saves/`) загружаются с теми же id и числами; круговой проход «сохранить → загрузить → сохранить» даёт равные байты; перестановка констант enum в тесте не ломает загрузку.
