# 011. Бункер Сидоровича и торговля игрока

Выполнять после 002 и 009. Модель: обычная.

## Что сделать
1. NPC-торговец «Сидорович» на точке `trader` узла бункера: неуязвим, не ходит, фракция Торговцы; правый клик — существующее окно торговли (`TradeService`).
2. Ассортимент Кордона по канону ТЧ: патроны 9×18, 5.45, 12 калибр; ПМ, ПБ, обрез, АКС-74У; кожаная куртка, комбинезон новичка;
   бинты, аптечки, антирад, еда, водка; болты, детектор. Покупает: артефакты, части мутантов, оружие (с износом), КПК погибших.
   Склад и цены — из симуляции (товар везут курьеры из 002).
3. Наценка для игрока: игрок в фракции — множитель из 002 для его фракции; без фракции — как нейтрал; скидки v1.16 сохраняются поверх.
4. У входа в бункер — «тихая зона»: группировки не стреляют друг в друга в радиусе 12 блоков (NPC не начинают бой).

## Готово, когда
- Юнит-тест цены: для игрока-бандита цена выше, чем для одиночки, ровно на множитель; продажа артефакта пополняет склад Торговцев и списывает деньги через `Ledger`.
- Смоук-проверка: у точки `trader` есть сущность торговца. Пункт в `CHECKLIST.md`. Сборка зелёная, PR с блоком передачи смены.
