# 035. Бункер Сидоровича по оригиналу (+ список сборщиков в Prefabs)

**Линия: мир.** **Модель исполнителя: сильная.** После 031.

Собрать постройки узла по обмерам оригинала вместо «куч вокселей» — метод в `docs/kordon_objects/README.md`,
обмеры — `docs/kordon_objects/01-bunker.md`, образец кода — `zonemap/build/KordonSouthPost.java`.

## Что сделать
1. **Сначала** `Prefabs`: список сборщиков уровня (интерфейс: `List<int[]> clear()`, `void build(BlockSink, int lvl)`, точки), `clear/cleared/build/points` — по всем; `KordonSouthPost` — первый в списке.
2. Сборщик `KordonBunker`: вход в бункер (бетонный портал, дверь, лестница вниз), подземная комната торговца (стол, ящики, свет) —
   по канону: бункер за домами деревни; подземная часть — под входом, размеры комнаты не меньше 7×9×3.
3. Рабочее место `duty` для торговца — за столом.

## Готово, когда
- `bash tools/conveyor/check.sh` зелёный; `PrefabsTest` проверяет новый сборщик; статус карточки обновлён; пункт в `CHECKLIST.md`
  («Бункер Сидоровича — постройки ровные, с входами и крышами, на тех же местах»).
