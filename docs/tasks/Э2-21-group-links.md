## Что сделать
1. `GroupLink`: ведущая группа, зависимая группа, тип связи, доля 0…1, поддержка (люди, снабжение, защита), напряжение 0…1.
2. Шесть связей Кордона ровно по списку:
   - Деревня новичков ← Свиноферма — **договор защиты, не подчинение** (хаб нейтрален);
   - Лагерь у вагончика ← Свиноферма — договор;
   - Дыра в заборе ← Свиноферма — договор;
   - Проводники тоннеля ← Свиноферма — договор, высокая склонность к отколу;
   - Разрушенный мост ← Южный блокпост — **приказ**, без доли;
   - Дальний блокпост ← АТП — **дань**, половина пошлины с перехода на Свалку.
3. Доля по идеологии ведущей силы: приказ — нет доли (снабжение сверху, добыча на склад); дань 30–50 %; договор 10–20 %.
4. Напряжение растёт: доля выше нормы идеологии, помощь не пришла, ведущая ослабла, амбиция командира зависимой, агрессивность. Падает: помощь, победы, повышения, общая угроза.
5. При пороге — событие по типу связи: договор → мирный уход (самостоятельность или другая ведущая); дань → мятеж, нападение на ведущую; приказ → дезертирство людей поодиночке, группа не откалывается. Событие явное, в журнале.
6. Доля и поддержка проходят через `Ledger` существующими кассами и конвоями; новых маршрутов не вводить.
