## Что сделать
1. **`ContractBoard.courierAmbushed`**: сейчас только платит игроку, а курьер Торговцев (`Caravan` с `courierFor >= 0`
   из `courierInTransit`) продолжает путь и доставляет груз. Нужно: найти этот караван (цель контракта: `c.node` —
   пункт назначения, `c.qty` — `courierFor`), снять его из `s.caravans` с потерей груза **так же, как при обычном нападении
   на караван** (найди существующий код нападения на караваны в `Simulation`/`UtilityBrain` и переиспользуй его, не пиши новый).
   Груз до получателя не доходит. Если курьер уже доставил груз или исчез — контракт проваливается, награды нет.
2. **`ContractBoard.raidedFarm`**: при нуле еды не брать `Math.max(1, …)` «из воздуха». Если еды на узле нет —
   контракт `RAID_NODE` не выдаётся (проверка при выдаче), а при выполнении берётся `min(запас, доля)`.
3. **Дедупликация `AMBUSH_COURIER`** — по реальной цели (тот же курьер/`courierFor`), а не по узлу −1.
4. `KordonBalance.CONTRACT_RAID_FARM = 10`: вместо номера узла — поиск узла «Свиноферма» по имени/типу из сценария
   (или константа в `KordonScenario`, если там есть именованные индексы).
5. Тест (`KordonContractsTest`): засада на курьера → караван снят, у получателя груз не прибавился;
   `RAID_NODE` не выдаётся узлу без еды; тест `npcDoNotTakeBanditContracts` должен падать, если за период
   не появилось ни одного контракта Бандитов (не проходить вхолостую).
