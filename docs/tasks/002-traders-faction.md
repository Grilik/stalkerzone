# 002. Торговцы — нейтральная группировка с курьерами

**Линия: симуляция.**

Выполнять после 001.

## Зачем
Торговец (Сидорович) нейтрален ко всем. Группировки не должны сталкиваться у него в бункере:
товар им развозят курьеры торговца. Наценка зависит от группировки покупателя.

## Что сделать
1. Новая фракция «Торговцы» с новым id **в конце** списка (не менять существующие id). Нейтральна ко всем:
   строка и столбец в матрице вражды нулевые, её никто не атакует, она никого не атакует.
   Матрица и массивы, зависящие от числа фракций, расширяются; сохранения старых версий читаются
   (новая фракция добавляется при загрузке) — поднять версию формата.
2. В `KordonScenario` бункер Сидоровича принадлежит Торговцам.
3. **Курьеры.** Сейчас группировки ходят торговать к узлу-торговцу сами (см. `Caravan`/`Logistics`).
   Для торговца, принадлежащего Торговцам, закупку группировки доставляет караван Торговцев от бункера до
   базы группировки и обратно (с деньгами). Используй существующий механизм караванов, не пиши новый.
   Курьер может погибнуть по дороге (опасность рёбер), тогда товар и деньги теряются как у обычного каравана.
4. **Наценка по группировке.** Цена для группировки = базовая цена × множитель от отношения Торговцев к ней:
   союзники −5%, нейтралы 0%, «подозрительные» (бандиты) +15%. Множители — константы в одном месте.

## Не делать

## Готово, когда
- Тест `TradersTest`: Торговцы ни с кем не воюют; за 10 дней на Кордоне есть ≥1 доставка курьером каждой из
  трёх группировок; ни одна группировка не входит в бункер торговать сама; цена для бандитов выше, чем для
  одиночек, ровно на заданный множитель; сохранение старой версии загружается с фракцией Торговцев.
- Все тесты и `./gradlew.bat build` зелёные, в PR — блок передачи смены.
