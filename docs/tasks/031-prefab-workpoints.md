# 031. Рабочие места из построек по оригиналу

**Линия: мир.** Модель: обычная. После 028.

Постройки по оригиналу (`zonemap/build/Prefabs`, образец — `KordonSouthPost`) сами знают, где площадка вышки, где нары,
где шлагбаум. Пусть сборщик вместе с блоками выдаёт **рабочие места** — тогда каждая новая постройка размечена автоматически.

## Что сделать
1. `zonemap/build/Prefabs` (чистая Java): `record Point(String kind, int x, int y, int z)` и
   `List<Point> points(String levelId, Ground g)`. Внутри сборщиков — метод `mark(kind, x, y, z)` (через тот же проход сборки,
   без второй постройки блоков). Виды: `guard` (пост часового), `bed` (спальное место), `cook` (у костра), `work` (мастерская/техника),
   `rest` (лавка), `patrol` (точки маршрута по порядку), `duty` (дежурный внутри здания), `gate` (у шлагбаума).
2. `KordonSouthPost` выдаёт (y — пол над землёй/площадкой, считает сборщик):
   - `guard`: центр площадки каждой из трёх вышек (на уровне площадки + 1);
   - `gate`: (55, z 207) и (61, z 205) — у проезда в мешках;
   - `duty`: внутри двухэтажной части КПП (73, z 215), первый этаж;
   - `bed`: у нар казармы — x 86 и x 97, z 232…248 через 3;
   - `cook`: (77, z 241); `rest`: (76, z 240) и (80, z 240) — лавки;
   - `work`: у БТР (72, z 242) и у гаража через дорогу (34, z 214);
   - `patrol`: обход внутри забора по углам (68,213) → (102,213) → (102,256) → (68,256) и выход на дорогу (57,195) → (57,262).
3. `npc/NpcManager`: если у узла есть точки из `Prefabs.points` (узел — тот, в чьих границах замены лежит центр узла;
   для `l01_escape` это «Южный блокпост»), брать места появления и работы оттуда; иначе — как сейчас из `LevelPoints`.
4. `PrefabsTest`: у блокпоста ≥3 `guard`, ≥10 `bed`, ≥4 `patrol`; все точки в границах замены; точка `bed` не внутри твёрдого блока
   (по карте блоков сборщика).
