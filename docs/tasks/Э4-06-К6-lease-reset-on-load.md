# Э4-06-К6. После загрузки аренд нет

Автор: Fable, 16.11

**Конвейер:** да
**Тест:** `src/test/java/ru/stalkerzone/sim/LeaseResetOnLoadTest.java`
**Файлы:** `sim/Simulation.java` (save/load), `sim/Embodiment.java`
**Чек-лист:** нет
**Видно в игре:** после аварийного закрытия игры двойников NPC нет

## Что сделать
Аренды в сохранение не пишутся. При сохранении с действующими арендами состояние арендованных берётся из последнего отчёта (или позиции на момент выдачи). После загрузки все люди — записи на последних известных позициях; их вещи — при них или в `worldLoot` узла, ничего не уничтожается.

## Готово, когда
«Выдать аренду → сохранить → загрузить»: аренд 0, число людей по группам прежнее, `audit()` сходится; повторная материализация после загрузки разрешена.
