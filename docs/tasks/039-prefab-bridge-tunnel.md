# 039. Мост, насыпь и туннель с электрами по оригиналу

**Линия: мир.** **Модель исполнителя: сильная.** После 035.

Собрать постройки узла по обмерам оригинала вместо «куч вокселей» — метод в `docs/kordon_objects/README.md`,
обмеры — `docs/kordon_objects/08-bridge.md` и `07-tunnel.md`, образец кода — `zonemap/build/KordonSouthPost.java`.

## Что сделать
1. Рухнувший ж/д мост — пролёты и опоры по обмерам; **пространство под мостом используется** (укрытие поста военных: мешки,
   навес, ящики) — плейтест «мост должен быть мостом».
2. **Туннель под насыпью с электрами** — настоящий проход (свод 3×4, бетонные стены) сквозь насыпь по месту туннеля;
   аномальное поле электр (карточка 029) — внутри туннеля.
3. Рабочие места поста на мосту: `gate` у шлагбаума, `guard`, `bed` под мостом.

## Готово, когда
- `bash tools/conveyor/check.sh` зелёный; `PrefabsTest` проверяет новый сборщик; статус карточки обновлён; пункт в `CHECKLIST.md`
  («Мост и туннель — постройки ровные, с входами и крышами, на тех же местах»).
