# 013. Аномалии, радиация и выброс на Кордоне

**Линия: мир.** **Шаблон локации:** всё, что здесь сказано про Кордон, реализуй через данные локации (файл точек `data/stalkerzone/points/<levelId>.json` и узлы сценария), без хардкода Кордона в коде мира — следующие локации должны заработать только добавлением их файла точек. Кордон — первый экземпляр.

Выполнять после 009. Модель: обычная.

## Что сделать
1. В сценарии `kordon` аномалии (через существующие `Anomaly`/`AnomalyManager`):
   - **туннель**: поле из 6–9 ELECTRA, артефакты «Вспышка» (шанс выше обычного ×3);
   - **дыра в заборе**: SPRINGBOARD, WHIRLIGIG, MOSQUITO, радиоактивная техника; артефакты «Колобок», «Каменный цветок», «Душа» (редко);
   - **разброс**: 2–4 трамплина/плеши у дорог на север, 1–2 жарки у сгоревших домов, туман в овраге у элеватора.
   - Новые типы не добавлять.
2. Радиация: ж/д насыпь (цистерны), техника у дыры, ферма — пятна через тег `stalkerzone:radioactive` или зону.
3. Выброс: точки `shelter` из `kordon_points.json` — укрытия (подвалы деревни, бункер, туннель, ангары АТП); NPC бегут в ближайшее;
   после выброса аномалии меняют место **внутри своего района** (туннель остаётся полем электр), артефакты зреют заново.

## Готово, когда
- Тест `KordonAnomaliesTest` (симуляция): состав аномалий по районам; после выброса все аномалии остались в своих районах; артефакты туннеля — электрические.
- Смоук: `zone anomalies` показывает ≥15 аномалий; `zone emission` не роняет сервер, после него `zone audit` проходит.
- Пункт в `CHECKLIST.md`, сборка зелёная, PR с блоком передачи смены.
