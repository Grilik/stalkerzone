## Что сделать
Критерий изменён ревизией (г-П9): стройки нет. Группа оценивает зоны потенциала (нужда в ресурсе, угрозы по знаниям, длина снабжения, свободные люди) → разведка (уверенность ≥ 0,6) → отряд занимает существующие постройки зоны → сектор работает при людях и снабжении. Лимит: `люди / 8` узлов на фракцию. Снабжённость < 40 % 10 дней подряд — оставление с эвакуацией склада. Выброс точку не отнимает. Блоки не заказываются.

## Готово, когда
Точка занимается только после разведки; без снабжения сектор не работает; при снабжённости < 40 % 10 дней точка оставлена, склад вывезен или «на поле», `audit()` сходится; лимит узлов не превышен за 365 дней.
