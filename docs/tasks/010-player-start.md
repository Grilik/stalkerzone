# 010. Старт и смерть игрока на Кордоне

Выполнять после 009. Модель: обычная.

## Что сделать
1. Новый игрок появляется на точке `spawn` (деревня новичков) — один раз, флаг в persistent data игрока.
2. Стартовый набор как в ТЧ (существующие предметы `ModItems`/TaCZ): ПМ с 2 магазинами, нож, кожаная куртка, 2 бинта,
   1 аптечка, хлеб, консервы, КПК, 10 болтов, детектор «Отклик», 500 руб. Список — константы в одном месте.
3. Смерть: игрок без фракции возрождается в деревне, во фракции — на её главной базе Кордона (`PlayerFaction`, уже есть потеря снаряжения).
   Тело/рюкзак с вещами остаётся на месте смерти на 20 мин (если уже есть — не дублировать).
4. Сообщение при первом входе: краткое вступление (2–3 строки, стиль ТЧ) и подсказка «КПК — клавиша …».

## Готово, когда
- Тест `PlayerStartTest` (без Minecraft): выбор точки возрождения (без фракции → деревня; во фракции → её главная база; база потеряна → деревня)
  и состав стартового набора по списку констант.
- Смоук-проверка: блок под точкой `spawn` твёрдый, над ней 2 блока воздуха. Ручной пункт в `CHECKLIST.md`.
- Сборка зелёная, PR с блоком передачи смены.
