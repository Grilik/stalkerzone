# 040. Дальний (северный) блокпост по оригиналу

**Линия: мир.** **Модель исполнителя: сильная.** После 035.

Собрать постройки узла по обмерам оригинала вместо «куч вокселей» — метод в `docs/kordon_objects/README.md`,
обмеры — `docs/kordon_objects/11-far_post.md`, образец кода — `zonemap/build/KordonSouthPost.java`.

## Что сделать
Блокпост бандитов у выхода на Свалку: будки, мешки, вышка, ограждение — по обмерам (плейтест: «северный блокпост — непонятно что»).
Рабочие места: `gate`, `guard`, `cook`, `bed`, `patrol`.
