**Конвейер v2 (с 06.11, П-13, `docs/claude/06-conveyor-v2.md`).** Одна линия. Конвейер берёт только карточки с паспортом
«**Конвейер:** да» — падающий тест + узкое задание, которые пишет «Программист» (Claude в чате). Исполнитель —
`deepseek/deepseek-v4.1-flash`, **одна попытка**: ≤ 15 мин, `--retries 2`, ≤ $0,30 на карточку. Старшего Claude, правок по
ревью и автослияния нет: PR сливает человек; не вышло — PR с меткой «не вышло», карточка возвращается «Программисту».
Постройки, облик, интерфейсы и всё, что нельзя проверить тестом, конвейеру не отдаются. Метрики — `tools/conveyor/metrics.py`.

### Карточка для конвейера v2
```
# NNN. Коротко, что исправить

**Конвейер:** да
**Тест:** `docs/tasks/tests/<Имя>Test.java`      ← сейчас красный; конвейер кладёт его в src/test/java и не даёт менять
**Файлы:** `src/main/java/…/A.java`, `…/B.java`  ← что исполнитель может читать и менять (кроме них — только статус в этой таблице)
**Чек-лист:** нет                                ← или `docs/checklist/NNN-имя.md`

## Причина (найдена «Программистом»)   ← где ошибка, со ссылкой на метод
## Что сделать                         ← 1–3 пункта, без архитектуры
## Готово, когда                       ← тест зелёный + `bash tools/conveyor/check.sh`
```
Перед тем как поставить карточку в таблицу: тест красный на main (`bash tools/conveyor/check.sh --only <Имя>Test` после
копирования в `src/test/java`, потом убрать), и правка, которую ждёт карточка, делает его зелёным. Паспорт проверяет
`ConveyorTest` (CI). Запуск: Actions → conveyor → Run workflow (номер карточки или пусто — следующая);
после слияния PR карточки конвейер сам берёт следующую.

# «Кордон 1.0»

Одна карточка = одна задача для агента в Cline = один PR. Подключение и цикл работы — `SETUP.md`.
Карточки с исполнителем «Claude» в Cline не запускать.

Как выполнять (кратко):
1. `git checkout main && git pull`, ветка `task/NNN-коротко`.
2. Новая задача в Cline: «Выполни docs/tasks/NNN-....md». Режим Plan → прочитать план → Act.
3. Локально: `powershell -ExecutionPolicy Bypass -File tools/simtest.ps1` и `./gradlew.bat build` (с 009 — ещё `tools/smoketest.ps1`).
   Пункты проверки в игре — новый файл `docs/checklist/NNN-<имя карточки>.md`, не `CHECKLIST.md` (П-06).
4. `gh pr create`, описание — блок передачи смены из `.clinerules`. После зелёного CI — Squash and merge.
   Конвейер свои PR не сливает (v2): сливает человек.
