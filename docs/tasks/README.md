# Карточки задач

Одна карточка = одна задача для агента в Cline = один PR. Порядок выполнения — по номеру.
Дизайн среза «Кордон 1.0» — в проекте (документ `stalker-mod-kordon-1.0`), кратко повторён в каждой карточке.

Как выполнять:
1. `git checkout main && git pull`, ветка `task/NNN-коротко`.
2. Новая задача в Cline: «Выполни docs/tasks/NNN-....md». Режим Plan → прочитать план → Act.
3. Локально: `powershell -File tools/simtest.ps1` и `./gradlew.bat build` — оба зелёные.
4. `gh pr create`, описание — блок передачи смены из `.clinerules`.
