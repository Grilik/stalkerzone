# 033. Население базы по симуляции

**Линия: мир.** Модель: обычная. После 032.

Плейтест: на базах 1–2 NPC. Сейчас `NpcManager.target` берёт ~12% членов группировки и режет до `MAX_PER_NODE = 8`.

## Что сделать
1. Число NPC узла, когда игрок рядом = **люди группировки, которые сейчас на этом узле по симуляции** (гарнизон узла; если
   в симуляции нет явного гарнизона — доля членов по числу узлов, главная база ×2), потолок **12** для баз (`BASE`) и
   **6** для остальных узлов, минимум 2 на занятом узле. Потолок — константа рядом.
2. Ушедшие на задание (атака, караван, сопровождение, контракт — по данным симуляции) на базе не появляются.
3. Лишние при уменьшении гарнизона уходят «по делам» (идут к краю зоны узла и исчезают вне поля зрения), а не пропадают на глазах.
4. Тест на чистой части: формула числа NPC (гарнизон 30 → 12, 5 → 5, ушли 3 из 5 → 2).

## Готово, когда
- Сборка и тесты зелёные; пункт в `CHECKLIST.md`: на южном блокпосте 8–12 военных.
