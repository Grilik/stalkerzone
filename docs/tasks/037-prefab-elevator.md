# 037. Элеватор по оригиналу

**Линия: мир.** **Модель исполнителя: сильная.** После 035.

Собрать постройки узла по обмерам оригинала вместо «куч вокселей» — метод в `docs/kordon_objects/README.md`,
обмеры — `docs/kordon_objects/04-elevator.md`, образец кода — `zonemap/build/KordonSouthPost.java`.

## Что сделать
Элеватор (высокая башня и корпус), склады и навесы вокруг, забор. Башня — бетон, этажи через 4, лестница внутри до верха;
корпус — по обмерам. Рабочие места: `guard` наверху башни, `bed` в складе, `cook` во дворе, `patrol`.
