## Что сделать (`src/main/java/ru/stalkerzone/npc/CaravanManager.java`)
1. **Цикл появления сломан.** В `tick` после `int alive = 0;` стоит `for (List<StalkerEntity> list : spawned.values())`
   **без тела**, и следующий цикл `for (int i = 0; i < sim.caravans.size(); i++)` стал его телом. Пока отрядов нет —
   караваны в мире не появляются вообще; когда есть — перебираются по нескольку раз. Нужно: `alive += list.size()`
   в теле первого цикла, второй цикл — отдельно, с проверкой лимита 24 NPC (`alive + размер отряда <= лимит`).
   Поправить отступы в этом методе.
2. **Привязка отряда к каравану по индексу** в `sim.caravans` ломается, когда караваны удаляются (индексы сдвигаются):
   смерть NPC списывает груз чужого каравана. Привязывать к самому объекту каравана (`IdentityHashMap<Caravan, …>`),
   а исчезнувшие из `sim.caravans` караваны — снимать вместе с отрядом. Формат сохранения симуляции не менять.
3. Проверить п. 2 карточки 014 (проход через насыпь — туннель/мост/дыра — по решению симуляции): если маршрут берётся
   из рёбер сценария и проходы различаются рёбрами — записать это в «Решения» PR; если нет — путевые точки строить
   по выбранному проходу.
4. Списание груза `ledger.destroyed[...] +=` — допустимо (так же сделано в `Arms`), не трогать.
