# 036. АТП по оригиналу

**Линия: мир.** **Модель исполнителя: сильная.** После 035.

Собрать постройки узла по обмерам оригинала вместо «куч вокселей» — метод в `docs/kordon_objects/README.md`,
обмеры — `docs/kordon_objects/05-atp.md`, образец кода — `zonemap/build/KordonSouthPost.java`.

## Что сделать
Гаражи и мастерские АТП (объекты 2, 3, 4, 6 — кирпич/доски/бетон, двускатные и плоские крыши), будки, водонапорная башня/вышки
(малые высокие объекты), забор по периметру, техника. **Входы**: ворота гаражей и двери с каждой длинной стороны (плейтест: «отсутствуют
входы/выходы»), крыши без дыр на уровне 2+. Рабочие места: `guard` на вышках, `work` у техники, `bed` в мастерской, `patrol` по периметру.

  («АТП — постройки ровные, с входами и крышами, на тех же местах»).
