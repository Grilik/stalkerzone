# 001. Сценарий «Кордон 1.0» в симуляции

**Линия: симуляция.**

## Зачем
Делаем играбельный срез из одной локации. Симуляция должна уметь запускаться не на всей Зоне
(`ZoneScenario`), а только на Кордоне с тремя группировками.

## Что сделать
1. **`sim/Scenarios.java`** — единая точка выбора сценария: `Simulation create(String id, long seed)`,
   id `"zone"` (текущий `ZoneScenario.create`) и `"kordon"`. Текущий id берётся из системного свойства
   `stalkerzone.scenario`, по умолчанию `"kordon"`.
   Заменить все прямые вызовы `ZoneScenario.create(...)` вне самого `ZoneScenario` на `Scenarios`
   (сейчас: `ZoneData`, `world/ZoneBiomes`, `world/ZoneWorld`, `world/WorldDecorator`, `sim/SimMain`,
   `sim/Simulation.load`, `zonemap/RoadNet`).
2. **Сохранение помнит сценарий.** `Simulation` хранит id сценария; `save` пишет его, `load` пересоздаёт
   статическую часть через тот же сценарий. Поднять версию формата; старые сохранения (без id) читаются как `"zone"`.
3. **`sim/KordonScenario.java`** — узлы Кордона (координаты в единицах ×10 блоков, деревня новичков = (0,0),
   север = −Z). Координаты ниже примерные — вынести в одну таблицу констант с комментарием
   «уточнить по меткам игрока»:

| Узел | Тип | Владелец | Примерно (x, z) |
|---|---|---|---|
| Деревня новичков | BASE | Одиночки | (0, 0) |
| Бункер Сидоровича | BASE, `trader` | никто (нейтральный) | (12, 13) |
| Южный блокпост | BASE | Военные | (27, 20) |
| Большая земля (выход за карту) | выход | — | (28, 31) |
| Элеватор | RUINS | никто (спорный) | (21, -29) |
| АТП | BASE | Бандиты | (61, -25) |
| Тёмная долина (выход за карту) | выход | — | (96, -23) |
| Туннель с электрами (к западу от моста) | ANOMALY | — | (0, -48) |
| Разрушенный мост | BASE | Военные | (27, -48) |
| Дыра в заборе (к востоку от моста) | RUINS | — | (55, -48) |
| Свиноферма (северная ферма) | SETTLEMENT | Одиночки | (1, -70) |
| Дальний блокпост | BASE | Бандиты | (30, -96) |
| Путь на Свалку (выход за карту) | выход | — | (30, -107) |

   Расположение — по канону ТЧ (карта: https://claude.ai/artifact/6o79Fxchqp4YzTU8Fqijbi).
   Новые узлы добавляй в конец списка: на порядок опираются сохранения.

   Для выходов за карту используй то, как в `ZoneScenario` сделан выход на Большую землю у торговцев;
   если подходящего типа нет — отметь в PR, новый тип не придумывай.
4. **Граф.** Южная часть (деревня, бункер, южный блокпост, Большая земля, элеватор, АТП, Тёмная долина)
   и северная (свиноферма, дальний блокпост, путь на Свалку) соединяются **только** через три узла-прохода:
   туннель (высокая `dangerPerDay`), мост (низкая) и дыру (высокая). Внутри частей — обычные дороги.
5. **Группировки.** Список фракций тот же, что в `ZoneScenario` (те же id и матрица вражды — от них зависят
   сохранения и массивы), но узлы и люди есть только у Одиночек, Военных и Бандитов. Остальные фракции —
   без узлов и без людей; их ИИ не должен падать.

## Учти
- Забор мира (`ZoneBounds.fromNodes`) и раскладка лагерей/дорог берутся из узлов сценария, поэтому
  со сценарием `kordon` граница мира сузится до Кордона. Это ожидаемо; проверка в игре — отдельная карточка.

## Не делать
- Пошлину и правила допуска на мосту, курьеров торговцев — это карточки 002 и 003.
- Не трогать `ZoneScenario` (кроме того, что нужно для `Scenarios`), `world/xray`, `tools/xray`.

## Готово, когда
- Новый тест `src/test/java/KordonScenarioTest.java` проверяет:
  - узлы и владельцы как в таблице;
  - любой путь между южной и северной частью проходит через туннель, мост или дыру
    (удалить по очереди все три узла-прохода → части не связаны; вернуть любой один → связаны);
  - 10 игровых дней симуляции без исключений, у каждой из трёх группировок остаётся ≥1 узел и ≥1 человек;
  - `save` → `load` даёт тот же сценарий и то же число узлов;
  - старое сохранение `"zone"` (сделать в тесте через `Scenarios.create("zone")` + save) загружается как `"zone"`.
- Все существующие тесты проходят (`tools/simtest.ps1`), `./gradlew.bat build` зелёный.
- В PR — блок передачи смены.
