## Инструменты врут в известных местах

24.11 он выдал ~260 веток, реально без слитого PR было 8. Признак истины —
gh pr list --state merged, а не топология git.

остаётся в run, новый загружается с тем же именем, deploy-pages падает на
Multiple artifacts. Восстановление — gh workflow run dashboard.

Патч по шаблону может не совпасть из-за отсутствия завершающего перевода
строки. Проверять результат, а не считать успехом молчание.

Проверка, которая молчит при провале, бесполезна. Валидатор возвращал 1,
но ничего не печатал. Требовать и код, и сообщение.

## Ничего не теряем

Удаление — только после сверки (MD5 для миров, список уникальных файлов для
веток). Остальное — архив внутри репозитория или карантин TRASH.
Ветки не удалять при снятии worktree.

## Порядок работы

Один PR — одна задача. Слияние — только пользователем. Обязательные ворота:
build/build и build/server. dashboard/page — витрина, не ворота.

Реестр правится руками, производные файлы — генерируются. Ручная правка
производного после А38 не пройдёт CI.

Идея → запись в реестр → задача со статусом. Решение → строка в DECISIONS.md.
Без записи не считается сделанным.
## Кодировка файлов реестра

project-tasks.json и генерируемые файлы — UTF-8 БЕЗ BOM. PowerShell 5.1
Set-Content -Encoding UTF8 пишет с BOM — битый JSON, падают сборка и CI.
Использовать [System.IO.File]::WriteAllText(, , (New-Object System.Text.UTF8Encoding False))
или Python с encoding="utf-8". Проверено 24.11: битый файл ломал сборку страницы
с ошибкой «Unexpected UTF-8 BOM».
