# Навыки штаба (уроки сессий 24-27.11.2026)
Читать перед любой работой. Формат: симптом -> правило -> проверка.

1. Память в репозитории, не в чате. Симptom: задача/долг теряется при смене модели. Правило: реестр + DEBTS.md + журнал — единственный авторитет; чат не источник состояния. Проверка: audit_ids.py / validate.py.
2. Сначала чтение, потом патч. Симptom: выдуманный якорь (get_stage, CONVEYOR.md). Правило: grep/Read файла до правки; якорь копируется из вывода, не из памяти. Проверка: патч печатает OK/НЕ НАЙДЕНО, не молчит.
3. Скрипт правки реестра: py_compile ДО запуска; from datetime import datetime (не import datetime); here-string @'...'@; не вставлять f-строки внутрь @"..."@. Проверка: python -m py_compile, exit 0.
4. Статус только с диффом и pr_number. Симptom: ложный TESTS_PASSED (А44). Правило: массовые правки статусов запрещены; закрытие = коммит с работой + PR. Проверка: validate + дифф PR.
5. Git-гигиена. Ветка на изменение; журнал переносить cherry-pick; после squash-слиния git reset --hard origin/main; case-only rename на Windows в два шага (X -> X_tmp -> x). Проверка: git status чисто, main == origin/main.
6. Пути: один конфиг tools/paths.py; игра != дамп (games\Anomaly vs dumps\stalker_dump); grep ловит оба стиля слэшей, экранированные \\ и голые имена папок. Проверка: grep вне конфига пуст.
7. Ворота: validate / check_links / check_deps / gen.py --check; smoke мира = tools/ci/e1_11_smoke.sh (не tools/thezone). Проверка: все exit 0.
8. Один ход = один блок команд с явным критерием готовности. Долги вести файлом DEBTS.md, не пересказывать список в чате. Проверка: пункт доски закрыт коммитом.
9. Честность объёма: не подменять вопрос (папки -> дубли); не заявлять «закрыто» без диффа; признавать повторные ошибки и вводить правило-предохранитель. Проверка: ревьюер сверяет заявление и дифф.

10. Воспроизводи вызов как в CI: дашборд собирается 'python3 -I tools/dashboard/build.py _site'; флаг -I не добавляет каталог скрипта в sys.path, поэтому локальные соседние модули импортируются через явную вставку пути. Проверка: python -I tools/dashboard/build.py _site без traceback.


11. dashboard.yml на pull_request_target собирает код BASE (main), не ветки PR. PR с фиксом дашборда показывает красный dashboard до слияния; зелёность оценивать после merge или run по main. Локальная проверка: python -I tools/dashboard/build.py _site.
