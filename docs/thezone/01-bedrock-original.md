# TheZone: оригинал Bedrock и что потеряно при конверсии в Java (Э1-01, Э1-02)

Дата: 15.11.2026. Исходник `C:\Users\vladi\Downloads\TheZone.mcworld` — Bedrock 1.19.22, 303 МБ LevelDB. Java-копия `C:\MineStalker\The Zone` — 1.20.1, после Chunker. Оба мира, архив и папка `The Zone` **только читались**.

Инструменты в `tools/thezone/`: `port_pack.py` (пак), `compare_worlds.py` (сравнение миров; читает LevelDB из архива без сторонних библиотек), `survey_map.py` (карта и материалы). Карта мира — `img/overview.png`, локации — `places.json`, материалы — `02-materials.md`.

## 1. Что внутри оригинала
- **Мир:** 461 996 чанков в обоих мирах, совпадает. Измерение одно, верхний мир.
- **Ресурспак** `resource_packs/TheZone`: 480 файлов. Это BDcraft Cubik by Sphax (64×64), перекрашенный под Зону. `manifest.json`: «Converted Using Resource Pack Converter» — пак когда-то перевели с Java на Bedrock, имена текстур эпохи Java 1.7.
  - блоки — 280 файлов, предметы — 92, сущности — 73 (банеры, сундуки, табличка, мобы);
  - окружение — 13 (солнце, луна, стадии разрушения), броня — 8, карта — 3, частицы — 1 атлас, картина — 1 атлас `kz`.
- **Поведенческого пака нет** (`behavior_packs` пуст). Вся логика карты сделана **командными блоками**.
- **Зал у точки появления (0, 34…41, 0)** — служебная комната автора:
  - таблички с названиями 19 локаций и командные блоки с телепортами под ними;
  - стенды «радиационное отравление», «голод», «экипировка скелетов и зомби», «бассейн для проверки радиации».
- По телепортам сняты координаты **всех 19 локаций** — `places.json`.

## 2. Что потеряно, искажено, цело

| Что | Bedrock | Java | Итог |
|---|---|---|---|
| Ресурспак | есть, включён в мире | нет (Chunker пак не переносит) | **потеряно → восстановлено** этим PR: 386 текстур перенесены, см. §3 |
| Блоки | — | — | **цело**. В выборке 40 чанков (232 секции) различия только в именах: старые имена Bedrock → новые Java. Например, `stone` с вариантом → `granite/andesite/diorite`, `wool` → `<цвет>_wool`, `planks` → `oak_planks`, `stained_hardened_clay` → `*_terracotta`. Пропущенных или заменённых чужими блоков не найдено. Полный поблочный подсчёт Bedrock не делался |
| Командные блоки | 14 982 | 14 982 | **искажено**. Блоки и команды перенесены, но команды остались в синтаксисе 1.12 / Bedrock: `score_X_min=`, `@a[lm=1,l=2]`, `/summon Villager … {Profession:1}`, `fill … minecraft:stone 0`, `effect @a … 10 5 4 true`. В Java 1.20.1 большая часть не выполнится. Механики автора на командах — радиация, артефакты, детектор, «голод», снаряжение мобов, телепорты — в Java **не работают**, кроме простых `tp` |
| Сундуки | 11 671 (`chest`) | 9 651 `chest` + 2 020 `trapped_chest` | **цело** по числу (11 671). Предметов внутри 641 → 617: **24 предмета потеряны** (видимо, без аналога в Java) |
| Прочие блочные сущности | печи 2 908, проигрыватели 1 999, спавнеры 397, раздатчики 317, воронки 130 и др. | те же числа | **цело** |
| Котлы | 932 | 0 как блочная сущность | **норма**: в Java 1.20 котёл — обычный блок; вода в котле переносится состоянием блока (не проверялось) |
| Головы поршней (`pistonarm`) | 867 | 0 | **норма**: в Java это состояние блока |
| Рамки предметов | 24 (в Bedrock блочная сущность) | 24 сущности `item_frame` | **цело** |
| Таблички | 388 | 388 | **текст: перенесены 37 табличек**. Это все надписи зала локаций и «EXIT» у (−2860, 51, −2337); у остальных строки пустые в Java. Прочитать текст на стороне Bedrock скрипт не смог: поле разобрано неверно (известное ограничение). Поэтому «потеряно» или «было пусто» для 351 таблички **не установлено** |
| Сущности (мобы, стойки, предметы) | ≈ 10 100: овцы ≈ 1 880, курицы ≈ 1 800, свиньи ≈ 1 700, коровы ≈ 1 470, кролики ≈ 780, волки ≈ 220, лошади ≈ 110, **стойки для брони ≈ 400**, картины 19, жители 15, предметы на земле ≈ 1 040, падающие блоки ≈ 240 | **0** (в `entities/` только 24 рамки) | **потеряно** — Chunker не перенёс старый формат сущностей (тег 0x32 LevelDB). Животные не нужны, но **стойки для брони** (≈ 400), **картины** и **жители** — декор и персонажи построек |

Идентификаторы сущностей Bedrock — числа старого формата: младший байт — тип (13 овца, 10 курица, 12 свинья, 11 корова, 18 кролик, 14 волк, 23 лошадь, 61 стойка, 83 картина, 15 житель, 64 предмет). Это сопоставление по известной таблице типов Bedrock, по NBT отдельно не проверялось — числа по видам приблизительные, общий итог (≈ 10 100 сущностей против 24 в Java) точный.

## 3. Перенос ресурспака (Э1-02)
- Скрипт `tools/thezone/port_pack.py`: таблица переименований 1.7 → 1.20.1 внутри скрипта.
  - Примеры: `wool_colored_*` → `*_wool`, `hardened_clay_stained_*` → `*_terracotta` (`silver` → `light_gray`), `log_oak` → `oak_log`, `planks_big_oak` → `dark_oak_planks`, `quartz_block_lines` → `quartz_pillar`, `stonebrick_*` → `*_stone_bricks`, `door_*_lower/upper` → `*_door_bottom/top`, `grass_side` → `grass_block_side`, `glass_*` → `*_stained_glass`, `reeds` → `sugar_cane`;
  - папки `blocks/items` → `block/item`, анимации `.mcmeta` перенесены, `pack.mcmeta` с `pack_format` 15.
- **Итог: перенесено 386, пропущено 58, не сопоставлено 0.**
- Пропущено, потому что в Java 1.20.1 нет отдельной текстуры или формат другой:
  - Bedrock-копии `*_carried`, `*_opaque`, файлы «- Copy», `reeds512`, `cobblestone_0…9`;
  - кровать (с 1.13 — текстура сущности), часы и компас (в 1.20 — кадры), `flower_paeonia`;
  - двойные сундуки (в 1.20 — половины left/right), черепа и жители (другой формат с 1.13/1.14);
  - атласы частиц `particles` и картин `kz`.
  - Эти 58 выглядят по-ванильному. Если понадобятся двойной сундук, жители или картина `kz`, их можно перерисовать вручную нарезкой атласов.
- Без пака ванильный вид будет и у тех, которых в паке нет совсем: `prismarine_bricks` (0,14 млн в мире), бетон и всё новое после 1.12.
- **Где лежит пак:**
  - `C:\MineStalker\modpack\resourcepacks\TheZone` и папка игры `…\Forge 1.20.1\resourcepacks\TheZone`;
  - включён в `options.txt` игры последним в списке `resourcePacks` (`file/TheZone`), копия до правки — `options.txt.bak-e1-01-2026-11-15`.
- **В git только скрипт**, текстуры пака не кладутся: BDcraft — авторский пак, версия у нас локальная.
- Пак переопределяет только ванильные текстуры. Блоки мода `stalkerzone:*` и TaCZ он не трогает.

## 4. Карта мира (`img/overview.png`)
- Масштаб: 1 пиксель картинки = 8 блоков (шаг съёмки 16, увеличение ×2). Цвет — по верхнему блоку, тень — по высоте. Сетка через 512 блоков с подписями. Красные кружки — 19 локаций из зала телепортов.
- **Все постройки — в западной трети мира** (x −5600…−600, z −4000…+4400):
  - север — Затон, Янов, Припять;
  - центр — Лиманск, Армейские склады, Мёртвый город, Бар, Янтарь;
  - юг — Свалка, Агропром, Тёмная долина, Кордон, Болота;
  - ЧАЭС (−622, 912) и Дуга (−1504, 3428) — восточнее.
- **Восточные две трети** (x > −500) — природный рельеф без построек: река с притоками, большое водохранилище (≈ x 0…3500, z 0…4500), леса, отмели. Полоса на юг (x ≈ 3600…4100, z до 8200) — продолжение реки.
- Геометрия похожа на Зону: север — Припять и Затон, юг — Кордон и Болота. Масштаб и взаимное положение локаций — авторские, не по глобальной карте ТЧ. Это вход для Э1-06 (соотнесение с уровнями оригинала).

## 5. Проверка в игре — **не выполнена Claude Code**
Сравнение «без пака / с паком» в одних и тех же местах требует запуска клиента. Предлагаемые 4 места: Кордон (−4118, 78, 3486), Бар (−4379, 76, 1277), Припять, центр (−2862, 65, −2312), ЧАЭС (−622, 71, 912).

Как проверить:
1. Создать копию мира (Э1-03), чтобы не трогать `The Zone`.
2. Войти без пака, сделать скриншоты в этих местах.
3. Включить пак «TheZone» в «Пакетах ресурсов», сделать скриншоты в тех же местах.
4. Положить скриншоты в `docs/thezone/img/` этого PR.

Пользовательский вид пака: локальные превью текстур `C:\MineStalker\modpack\resourcepacks\TheZone-preview-materials*.png` (в git не кладутся).
