# TheZone: таблица материалов (Э1-02)

Для сборщиков Э2: каким ванильным блоком TheZone «рисует» материалы Зоны и сколько его в мире. Вид — по текстурам ресурспака TheZone, перенесённого в Java (`tools/thezone/port_pack.py`, основа BDcraft Cubik by Sphax, перекраска автора TheZone). Без пака эти блоки выглядят как обычные ванильные: кварц, шерсть, губка, золото и т. д. Поэтому пак обязателен для вида Зоны.

**Подсчёт.** Делался точно по каждому 25-му чанку: 18 479 из 461 996 чанков, `tools/thezone/survey_map.py`. Оценка на весь мир — это результат × 25, поэтому числа дальше — порядок величины. Сырые данные лежат в `materials-sample.json`, первые 300 блоков. В чанках вне построек на 98 % камень, земля и вода, поэтому строительные блоки считаны грубее, но их порядок верен.

## Природа (для Э1-04 и границ)
- Камень — около 6,8 млрд, земля — 0,47 млрд, вода — 0,23 млрд. Трава: `grass_block` 81 млн, `grass` 12 млн.
- Листва: дуб 44 млн, ель 14 млн, берёза 3 млн. Песок 34 млн, гравий 19 млн.
- Андезит, гранит и диорит — по 14–15 млн: следы ванильной генерации.
- В паке трава серая: в Java её окрашивает цвет биома, поэтому вид травы зависит от биомов чанков. Биомы TheZone сохранились от конверсии.

## Вывод для сборщиков Э2
Строить в стиле TheZone значит строить из тех же ванильных блоков при включённом паке:
- бетон — `quartz_block`, `iron_block`, `smooth_stone*`;
- штукатурка — `*_terracotta`, `white_wool`;
- кровля — `nether_bricks`*;
- мешки — `sponge`;
- плитка — `emerald_block`, `lapis_block`;
- полосы — `gold_block`.

Блоки мода `stalkerzone:zm_*` выглядят иначе. Если ставить их рядом, вид разойдётся. Решение «ванильные блоки под пак или блоки мода» — вопрос к архитектуре Э2, он передан в Э0-21.
