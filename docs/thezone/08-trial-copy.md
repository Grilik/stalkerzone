## Что нашла сверка захода 1 (TheZone-visit, 15.11, свежий мод)
`python -I tools/thezone/trial_copy.py check C:/MineStalker/world/work "<saves>/TheZone-visit"`: байты изменились у 16 регионов (игра пересохраняет загруженные чанки); блоков мода нет. Изменилось 4 622 блока в 47 чанках — всё обычная жизнь мира Minecraft:
- 4 244 — свойства листвы (`distance`): Chunker записал всем листьям `distance=1`, игра пересчитывает;
- 323 — выросшие из саженцев ели (воздух → листва, саженец → ствол) у дороги на Свалку (−4170, 92, 2846);
- 29 — трава под постройками стала землёй (руины хутора, АТП);
- дверь бункера Сидоровича (−4448, 60–61, 3808) исчезла (пользователь её не ломал). За дверью — механизм автора из Bedrock: «часы» из двух воронок с палкой → компаратор → командный блок `testfor @p[r=3]` → компаратор под дверью (автоматическая дверь при подходе игрока). В Java команды `testfor` нет (в блоке ошибка в 23:48:04 — время захода), механизм не работает. Модом дверь не трогается (код мода ванильные двери не меняет), предмета-двери рядом не осталось. Точная причина по данным не установлена. **В рабочей и опытной копиях дверь на месте**; заход 2 покажет, повторится ли (сверка `check` назовёт чанк). По решению пользователя (16.11) механизм убран правкой `e0006` (`03-world-edits.md`), дверь оставлена; регион r.-9.7 опытной копии обновлён из рабочей (все регионы снова совпадают). Дверь осталась железной, по решению пользователя у неё кнопки с обеих сторон (правка `e0007`);
- 18 пустых сундуков у южного края данных (−4784…−4769, z ≈ 4250) потеряли блок-сущности (блоки на месте).

**Листва (исправлено 16.11, правка `e0005`):** у всей листвы TheZone было `persistent=false` (выборка 300 чанков: 26 208 листьев, постоянных — 0); листья дальше 6 блоков от ствола игра со временем удаляет — кроны автора осыпались бы. По решению пользователя `tools/thezone/leaves_persistent.py` поставил всей листве рабочей копии `persistent=true`: 356 регионов, 164 932 чанка, 280 125 элементов палитры; в 127 чанках, где постоянная листва уже была, палитра разобрана и одинаковые элементы слиты. Проверка по резерву (3 региона, 3 072 чанка): изменилось только свойство `persistent`, блок-сущности те же; `world_edit_log.py verify` — ok. Откат: `python -I tools/thezone/world_edit_log.py undo C:/MineStalker/world/work e0005`. Опытная копия пересоздана после правки (прежняя — `saves\TheZone-trial-old-before-leaves`, не нужна). Случайные тики в опытной копии всё равно выключены — саженцы не растут, трава не гибнет, сверка ловит только мод.
