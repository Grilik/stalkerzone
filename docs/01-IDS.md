# Реестр идентификаторов Living Zone

Единственный регистратор ID. Номер, которого нет здесь, не существует.
Правила: ID выдаёт один владелец (штаб); снятые номера не переиспользуются;
таблица только дописывается; переименование — через алиас-таблицу ниже.

## 1. Пространства имён

| Префикс | Сущность | Владелец | Примечание |
|---|---|---|---|
| `R-<DOM>-NN` | требование | штаб | 132 в реестре |
| `Э<N>-NN` | задача этапа | штаб | 180 в реестре, номера не менять |
| `К###` | карточка конвейера | штаб | К1–К32 заняты |
| `А###` | карточка аудита/штаба | штаб | принято 24.11, см. §4 |
| `ПТ-#` | плейтест | пользователь | ПТ-1, ПТ-2 |
| `П-##`, `Т-##` | исторические задачи | — | сняты, не переиспользовать |
| `D#` | решение | штаб | D1–D8 + а–г |

## 3. Коллизия К-нумерации (найдена 19.11, разрешается 24.11)

Пакет аудита Qwen 18–19.11 занял номера конвейера. Совпадают К1/К15/К16.
Сталкиваются три:

| ID | Конвейер | Аудит | Статус аудита |
|---|---|---|---|
| К2 | person-registry (Э6-01), PLANNED | денежный баланс, гибель фракций | слит #207 |
| К5 | embodiment-lease (Э4-06), PLANNED | WarLedgerTest | слит #206 |
| К17 | InjuryStateTest (Э6-04), PLANNED | возрождение группировки | PLANNED |

Причина: два независимых регистратора без общего реестра ID.

**Решение штаба 24.11.2026 (принято):** конвейер сохраняет `К`, аудит переходит на `А`
с тем же номером. Слитые PR не переименовываются — связь через `pr_number`
и алиас-таблицу.

## 6. Известные расхождения

- `Faction.mercenary = true` стоит на Одиночках, метод `mercenaries()`
  возвращает Одиночек; Наёмники флага не имеют — задача А33 (К33).
- `KordonScenario village.owner = LONERS`, хотя деревня — нейтральный хаб;
  исправляется в Э2-23.
- Мёртвый город у Греха вместо Наёмников — Э5-10.
## 7. Зависимости и версии (зафиксировано 24.11.2026)

| Зависимость | Версия | Размер, байт | Где ставится |
|---|---|---|---|
| TaCZ | **1.1.8-hotfix2** | 57 472 579 | `modpack.ps1:30`, `get_tacz.ps1` |
| FramedBlocks | 9.4.3 | — | `modpack.ps1:32` |
| Forge / Minecraft | 47.x / 1.20.1 | — | целевая платформа |
| Java | 17 | — | сборка |

**Правило:** версия фиксированная, не «последняя доступная». Смена — отдельная
карточка с проверкой `compat/*` и боя на арене, не побочный эффект скачивания.

Основание: ПТ-1 и ПТ-2 пройдены с TaCZ 1.1.8. Мод общается с TaCZ через отражение —
при смене версии несовпадение имён классов и методов ломается молча, без ошибки
компиляции. 24.11 `get_tacz.ps1` брал «последний release» и поставил 1.2.0-hotfix:
среда разработки разошлась со сборкой модпака. Исправлено фиксированным URL
и проверкой размера.
