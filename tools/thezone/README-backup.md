# Резервирование и откат TheZone (Э1-03)

## Быстрый старт

### Создать резерв перед работой
```powershell
cd C:\MineStalker\stalkerzone-git\tools\thezone
.\backup_world.ps1 -Label "перед_Э2-01"
```

### Откатить после ошибки
```powershell
.\restore_world.ps1 -BackupName "2026-11-18_14-30-00_перед_Э2-01"
```

### Список доступных резервов
```powershell
Get-ChildItem C:\MineStalker\08_BACKUPS\thezone-backups\
```

## Структура

- **Оригинал:** `C:\MineStalker\The Zone\` (1.8 ГБ, не трогать)
- **Рабочая копия:** `C:\MineStalker\TheZone-work-fresh\` (правим здесь)
- **Резервы:** `C:\MineStalker\08_BACKUPS\thezone-backups\<метка>\`

## Что создаёт резерв

- `region/` — все регионы мира
- `level.dat` — настройки мира
- `entities/` — сущности (если есть)
- `checksums.md5` — MD5 всех файлов

## Безопасность

✅ Откат **проверяет MD5** перед восстановлением
✅ Откат **сохраняет текущее состояние** перед затиранием
✅ Резерв **проверяется** сразу после создания

## Когда делать резерв

- Перед **любой** правкой мира (Э1-10, Э1-12, Э2-01)
- После **успешной** задачи (для отката к хорошему состоянию)
- Перед **экспериментами** (проверка скриптов)
