# Резервирование и откат TheZone (Э1-03)

## Быстрый старт

```powershell
cd C:\MineStalker\stalkerzone-git\tools\thezone

# 1. Резерв перед работой
.\backup_world.ps1 -Label "перед_Э2-01"          # полный, с предобразами (~3.7 ГБ, ~1 мин)
.\backup_world.ps1 -Label "быстрый" -SkipPreimages  # без backup/, ~1.8 ГБ

# 2. Список резервов
Get-ChildItem C:\MineStalker\08_BACKUPS\thezone-backups\

# 3. Откат
.\restore_world.ps1 -BackupName "2026-11-18_02-02-09_перед_Э2-01"
```

Скрипты требуют **UTF-8 с BOM** — без него PowerShell читает файл как ANSI и кириллица ломает парсер.

## Структура

- **Оригинал:** `C:\MineStalker\The Zone\` (1.8 ГБ, не трогать)
- **Рабочая копия:** `C:\MineStalker\TheZone-work\` (3.7 ГБ, правим здесь)
  - `stalkerzone\edits.jsonl` — журнал правок e0004–e0014
  - `backup\` — предобразы для отката отдельных правок (1.9 ГБ, **не удалять**)
- **Резервы:** `C:\MineStalker\08_BACKUPS\thezone-backups\<метка>\`

## Что копирует резерв

| Что | Зачем |
|---|---|
| `region/`, `level.dat`, `entities/` | сам мир |
| `stalkerzone\WORKCOPY` | метка: без неё `world_edit_log.py` откажется править |
| `stalkerzone\edits.jsonl` | журнал правок — **без него откат правок невозможен** |
| `backup/` | предобразы правок e0004–e0014 |
| `checksums.md5` | MD5 всех файлов, проверяется сразу после создания |

Флаг `-SkipPreimages` пропускает только `backup/` — журнал и метка копируются всегда.

**Откат откатывает и журнал.** `edits.jsonl` вернётся к состоянию на момент резерва: правки, сделанные позже, исчезнут из журнала вместе с их предобразами. Это ожидаемо — мир и журнал остаются согласованными.

## Безопасность

✅ Резерв **проверяется MD5 сразу** после создания
✅ Скрипт **откажется** работать с папкой без метки `WORKCOPY` (оригинал не тронуть)
✅ Откат **проверяет MD5** резерва перед восстановлением
✅ Откат **сохраняет текущее состояние** (тоже полным резервом с журналом)
✅ Откат **не удаляет** папку целиком — только файлы, которых нет в резерве, и спрашивает про них
✅ Резерв **старого формата** (без `stalkerzone\WORKCOPY`) откатывать **запрещено** — он бы стёр журнал

## Когда делать резерв

- Перед **любой** правкой мира (Э1-10, Э1-12, Э2-01)
- После **успешной** задачи (точка возврата)
- Перед **экспериментами** со скриптами
