## Правила конвейера v2 (важнее .clinerules)
- Ты работаешь без человека, одна попытка, потолок по времени и деньгам. Цель одна: тест карточки зелёный, остальные тесты и сборка — тоже.
- Тест карточки (src/test/java/<Имя>Test.java) НЕ меняй: изменённый тест конвейер вернёт как было, а карточку отметит «не вышло».
- Меняй только файлы из списка выше. Чужие файлы — «не вышло», даже если тесты зелёные.
- Не читай файлы целиком, если они больше 300 строк: сначала поиск по имени метода, потом нужный диапазон строк.
- Проверка своего теста (быстро): `bash tools/conveyor/check.sh --only <Имя>Test`. Перед концом — полная: `bash tools/conveyor/check.sh` (первая строка — итог).
- Не делай git commit, push и PR — это делает конвейер. Не меняй .github/workflows, docs/claude/, build.gradle, gradle.properties.
- Если тест не удаётся сделать зелёным за 3 попытки — остановись и опиши причину в ESCALATE.md (он пойдёт в PR «не вышло»). Не обходи тест (не ослабляй проверки, не ловушки вида «если тест — вернуть ответ»).
- Временные файлы — в /tmp. docs/tasks/README.md не меняй: статус карточки конвейер ставит сам после слияния. Пункты проверки в игре — только если в карточке указан файл чек-листа.
