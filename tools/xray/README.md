# Уровни оригинальной игры 1:1 (tools/xray)

Делает из файлов вашей копии S.T.A.L.K.E.R.: Тень Чернобыля (Steam, Enhanced Edition) данные уровня для мода — `<id>.szl`.
Файлы игры и полученные из них `.szl` в репозиторий не кладутся: это данные GSC, у каждого игрока свои.

1. `xdb` — распаковщик архивов X-Ray (`*.db`): `make` скачает `LzHuf.cpp` из OpenXRay и соберёт.
   `xdb <archive.db> list` — оглавление, `xdb <archive.db> extract <dir> [маска]` — извлечь.
2. `rast <level.cform> esc.bin 1.0` — сетка 1 м: верх, земля, материалы, вода.
3. `vox <level.cform> vox.bin` — поверхностная вокселизация (постройки, мост, вышки).
4. `python3 export.py l01_escape.szl` — рельеф, покрытие, вода, постройки, подземелья, деревья в координатах мира
   (сдвиг уровня задан в начале файла).
5. Положить `.szl` в `<папка игры>/stalkerzone/levels/`.

Материалы: `gamemtl.xr` (id → имя), блоки по материалу — `XrayPlacer.material`.
