# Уровни оригинальной игры 1:1 (tools/xray)

Делает из файлов вашей копии S.T.A.L.K.E.R.: Тень Чернобыля (Steam, Enhanced Edition) данные уровня для мода — `<id>.szl`.
Файлы игры и полученные из них `.szl` в репозиторий не кладутся: это данные GSC, у каждого игрока свои.

1. `xdb` — распаковщик архивов X-Ray (`*.db`): `make` скачает `LzHuf.cpp` из OpenXRay и соберёт.
   `xdb <archive.db> list` — оглавление, `xdb <archive.db> extract <dir> [маска]` — извлечь.
2. `rast <level.cform> esc.bin 1.0` — сетка 1 м: верх, земля, материалы, вода.
3. `vox <level.cform> vox.bin` — поверхностная вокселизация (постройки, мост, вышки).
4. `python3 export.py l01_escape.szl` — рельеф, покрытие, вода, постройки, подземелья, деревья в координатах мира
   (сдвиг уровня задан в начале файла).
5. Положить `.szl` в `<папка игры>/stalkerzone/levels/`.

Материалы: `gamemtl.xr` (id → имя), блоки по материалу — `XrayPlacer.material`.

## Вся карта (v1.15)

Уровни раскладываются по глобальной карте игры (`config/game_maps_single.ltx`) с промежутками, чтобы не стояли впритык:

1. `python3 changers.py <dump>` → `levels.json`: границы уровней и переходы (`level_changer`) из `level.spawn`.
2. `python3 layout.py` — сдвиги уровней по глобальной карте, раздвижка до промежутка ≥170 блоков (Кордон на месте),
   высотный сдвиг `yoff`, чтобы земля была выше уровня моря.
3. `python3 export2.py <dump>/.../<id> <id>` — `.szl` каждого уровня; `python3 links.py` → `out/layout.json`.
4. Положить все `.szl` и `layout.json` в `<папка игры>/stalkerzone/levels/`.

Между уровнями мод сам поднимает рельеф до их высоты и прокладывает дороги-переходы там, где в игре был переход;
где дорога упирается в холм — туннель с бетонной обделкой и лампами.

## Уровни из Anomaly (v1.16)

Болота, Тёмная лощина, Свалка техники, Мёртвый город, Рыжий лес, Лиманск, Госпиталь берутся из S.T.A.L.K.E.R. Anomaly 1.5.x
(`db/levels/level_<id>.db0`; `xdb` читает и этот формат). Крупные архивы распаковывает `tools/converter.exe` из Anomaly.

1. `python3 remap.py <level.cform> <out.cform>` — материалы Anomaly к id ТЧ (`mtl.py` сравнивает два `gamemtl.xr`);
   пологие грани `default` — земля; наклонный «бетон» — скала (id 100, в моде — камень, андезит, булыжник).
   Прогоняется и для уровней ТЧ (скалы Радара, ЧАЭС).
2. `rast`/`vox`/`export2.py` — как обычно.
3. `python3 layout2.py <id…>` — новые уровни на глобальную карту Anomaly (подгонка по 11 уровням ТЧ), раздвижка ≥170 блоков.
4. `python3 pairs.py all.spawn` → `newpairs.json`; `python3 links2.py` — переходы по level_changer из `all.spawn`; концы дорог на сторонах уровней, смотрящих друг на друга.

## Детализация по рендер-геометрии (v1.17)

Постройки берутся не из коллизии, а из того, что игра рисует (`level` + `level.geom`; для ТЧ вырезаются по `geo_list.txt`,
для Anomaly — `converter.exe`):

- `lvl.py` — разбор `level` (шейдеры/текстуры, визуалы OGF) и `level.geom` (вершинные и индексные буферы);
- `geo2cform.py` — грани по категориям текстур (кирпич 200, штукатурка 201/223–225, бетон 202/203, доски 204/205,
  столбы 206, шифер 207, кровля 208, ржавчина 209, металл 210, решётки 211, стекло 212, двери 213, техника 214/215,
  колёса 216, ткань 217, плитка 219, пол 220, лампы 221, пни 222; скалы 100 — ещё и из коллизии) → псевдо-cform для `vox`;
  мелкие грани сразу сводятся к вокселям (экземпляры техники дают десятки миллионов граней);
  деревья — экземплярами (`trees.json`: место, высота, порода по текстуре листвы);
- `run.sh <id> <level> <level.geom>` — весь путь до `.szl` (рельеф по-прежнему из `level.cform`).
